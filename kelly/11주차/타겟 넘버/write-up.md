## 👀 제한 시간 안에 어디까지 해냈는가?

`17분 58초`만에 혼자서 문제를 해결할 수 있었다.

- 풀이 자체는 금방 떠올렸고, 초기 코드도 금방 작성했지만 시간 초과가 나는 케이스가 몇개 있어 시간을 제법 소요했다.
- 그래도 혼자서 시간 초과 원인을 찾아 코드를 수정해 문제를 해결하였다.

---

## 🧑‍🔬 문제 분석

n개의 음이 아닌 정수 리스트와 정수 target이 주어질 때 각 정수를 음수/양수 형태로 리스트 요소 순서를 지켜 더했을 때 target을 만들 수 있는 경우의 수를 구해 반환하는 문제이다.

문제에 주어지는 제약 조건은 다음과 같다.

### 제한사항

- 주어지는 숫자의 개수는 2개 이상 20개 이하입니다.
- 각 숫자는 1 이상 50 이하인 자연수입니다.
- 타겟 넘버는 1 이상 1000 이하인 자연수입니다.

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

완전 탐색/백트래킹을 활용하는 풀이를 생각했다. 주어진 정수 리스트의 요소 순서를 지키며 조건 검사를 해야하기 때문에 첫 번째 요소를 시작으로 -1/1을 곱해 누적하면서 마지막 요소까지 포함했을 때 누적된 합이 target을 만족하는지 검사 후 경우의 수를 업데이트하는 방식이다.

주어지는 입력의 크기가 매우 작기 때문에 충분히 완전 탐색/백트래킹 방식으로 해결할 수 있다고 판단했다.

- 결과적으로 올바른 풀이였다.

---

## 🏃 코드 작성 과정

### 내가 처음 작성한 코드

위에 기술한 풀이를 그대로 구현한 코드이다. 이 코드를 제출하면 최종 정답 처리를 받는다.

```python
def solution(numbers, target):
    # 메서드
    def recursive(cur, temp):
        nonlocal answer
        
        if cur == len(numbers):
            if sum(temp) == target:
                answer += 1
            return
        
        for number in [-numbers[cur], numbers[cur]]:
            temp.append(number)
            recursive(cur + 1, temp)
            temp.pop()
        
    # 메인 로직
    answer = 0
    recursive(0, [])
    
    return answer
```

## 🥰 배운점 & 느낀점

- 이번 문제는 혼자서 쉽게 풀 수 있었다.
- 다만 중간에 시간 초과가나는 케이스가 2개 발생했는데, 불필요한 반복 연산을 수행하고 있는게 원인이었다. 다행히 누적 형태를 빠르게 리스트로 변경하여 불필요한 연산이 발생하는 부분을 케치할 수 있었고, 10분정도 사용해서 시간 초과 로직을 해결할 수 있었다.
- 다만 이 10분도 제법 아까운 시간이니 처음부터 코드를 작성하기전 필요한 연산만 수행하는 코드를 작성할 수 있도록 훈련이 필요한거 같다.
