## 🧑‍🔬 문제 분석

[옷 이름, 옷 종류] 리스트로 구성된 2차원 리스트가 주어졌을 때 문제 조건에 맞춰 사용자가 코디할 수 있는 경우의 수 개수를 구하는 문제이다.

- 자세한 조건은 문제를 참고하자.

문제에 주어지는 제약 조건은 다음과 같다.

### 제한사항

- clothes의 각 행은 [의상의 이름, 의상의 종류]로 이루어져 있습니다.
- 코니가 가진 의상의 수는 1개 이상 30개 이하입니다.
- 같은 이름을 가진 의상은 존재하지 않습니다.
- clothes의 모든 원소는 문자열로 이루어져 있습니다.
- 모든 문자열의 길이는 1 이상 20 이하인 자연수이고 알파벳 소문자 또는 '_' 로만 이루어져 있습니다.

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

처음 생각했던 풀이는 다음과 같다.

1. 옷 종류와 각 종류별 개수를 키/벨류로 하는 딕셔너리를 초기화
2. 2 ~ 전체 옷 종류 개수의 조합을 전부 구해서 각 조합별 경우의 수를 모두 구한 후 딕셔너리 전체 키 개수와 합산해서 반환

문제는 위 풀이를 코드로 구현해 제출하니 시간 초과가 발생하는 케이스가 있었다. 높은 확률로 조합 부분에서 시간 초과가 발생하는거 같아 풀이 최적화를 고민해보니 굳이 조합을 구할 필요가 없다는 사실을 깨달았다.

```python
전체 옷 종류가 a, b, c, d가 있다고 가정할 때

문제 조건에 맞춰 코디할 수 있는 경우의 수는 각 종류별 개수 + 입지 않는 경우를 포함해 다음과 같이 구할 수 있다.

(len(a) + 1) * (len(b) + 1) * (len(c) + 1) * (len(d) + 1)

이 때 옷을 아예 입지 않는 선택지는 없으므로 모든 옷 종류를 걸치지 않은 경우의 수 1을 빼주면 구하고자 하는 전체 코디 개수가 나온다.
```

모든 조합을 구하는 대신 위 코드 에디터 속 공식을 사용하는 방향으로 코드를 수정하니 최종 정답 처리를 받을 수 있었다.

## 🧑‍💻 최종 정답 코드

### Python 풀이

- solution01

    ```python
    def solution(clothes):
        c_dict = {}
        
        for v1, v2 in clothes:
            c_dict[v2] = c_dict.get(v2, 0) + 1
        
        answer = 1
        for v in c_dict.values():
            answer *= (v + 1)
        
        return answer - 1
    ```


### Java 풀이

- solution01

    ```java
    import java.util.*;
    
    class Solution {
        public int solution(String[][] clothes) {
            Map<String, Integer> map = new HashMap<>();
            for (String[] c : clothes) {
                map.put(c[1], map.getOrDefault(c[1], 0) + 1);
            }
            
            int answer = 1;
            for (int v : map.values()) {
                answer *= (v + 1);
            }
            
            return answer - 1;
        }
    }
    ```
