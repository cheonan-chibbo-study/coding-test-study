## 🧑‍🔬 문제 분석

'A', 'E', 'I', 'O', 'U’ 만으로 구성된 문자열 word가 주어졌을 때 word를 구성하는 문자들로 1 ~ 5자리의 가능한 모든 문자열 사전을 만들경우 주어진 word는 사전에서 몇번째 문자열인지를 반환하는 문제이다.

문제에 주어진 제약 조건은 다음과 같다.

### 제한사항

- word의 길이는 1 이상 5 이하입니다.
- word는 알파벳 대문자 'A', 'E', 'I', 'O', 'U'로만 이루어져 있습니다.

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

풀이법은 쉽게 떠올릴 수 있었다.

1. A', 'E', 'I', 'O', 'U'로 만들 수 있는 1 ~ 5자리의 문자열을 모두 구해서 정렬한다.
2. 주어진 word가 1에서 만든 사전에서 몇번째 요소인지를 찾아 반환한다.

무식한 완전 탐색 풀이라 시간 초과가 걱정되기는 했지만 주어진 입력이 매우 작기 때문에 이 풀이를 사용해봤다. 결론적으로 이 풀이는 올바른 풀이였다.

내가 생각한 풀이로 문제를 해결할 수 있다.

## 🏃 코드 작성 과정

### 내가 처음 작성한 코드

작성한 코드는 다음과 같다. 이 코드를 제출하면 정답 처리를 받는다.

```python
from itertools import permutations

def solution(word):
    # 메인 로직
    char_list = []
    for c in ["A", "E", "I", "O", "U"]:
        for cnt in range(5):
            char_list.append(c)
    
    word_set = set()
    for size in range(1, 6):
        candi_list = permutations(char_list, size)
        for candi in candi_list:
            word_set.add("".join(candi))
    
    word_list = sorted(word_set)
    return word_list.index(word) + 1
```

### 찾아본 풀이로 작성한 코드 (시간 개선)

내가 처음 작성한 코드는 중복 문자열도 전부 만들기 때문에 시간이 오래 걸린다. 따라서 아래와 같이 코드를 작성하면 필요한 문자열만 만들기 때문에 훨씬 빠르게 실행된다.

```python
from itertools import product

def solution(word):
    words = []
    for i in range(1, 6):
        # 'AEIOU'에서 중복을 허용해 i개를 뽑음
        for p in product("AEIOU", repeat=i):
            words.append(''.join(p))
    
    words.sort()
    return words.index(word) + 1
```

- 기존에 사용한 `permutations`와 새롭게 사용한 `product`의 차이는 다음과 같다.
    - `permutations` vs `product` (순열 생성에 사용되는 요소를 중복해서 사용할 수 있는지 여부 차이)

      서은아, `product`와 `permutations`의 차이는 파이썬으로 완전 탐색 문제를 풀 때 가장 헷갈리면서도 아주 중요한 개념이야! 핵심만 딱 짚어주면 두 가지의 차이는 바로 **"사용한 원소의 중복(재사용)을 허용하느냐 마느냐"**에 있어.

      예를 들어 `['A', 'B']`라는 알파벳 카드 두 장을 가지고 2자리 글자를 만든다고 상상해 보자.

        - **permutations (순열)**: 한 번 뽑은 카드는 다시 쓸 수 없어! 그래서 나올 수 있는 글자는 `AB`, `BA` 딱 두 가지뿐이야. 손에 카드가 한 장씩밖에 없으니까 'AA'나 'BB'는 불가능하지.
        - **product (데카르트 곱 / 중복 순열)**: 쓴 카드를 다시 제자리에 돌려놓고 또 뽑을 수 있어! 마법의 주머니처럼 카드가 계속 무한정 있는 거야. 그래서 `AA`, `AB`, `BA`, `BB` 이렇게 네 가지 경우가 다 나올 수 있어.

      방금 네가 멋지게 풀었던 '모음 사전' 문제에서는 'A'를 5번 연달아 써서 'AAAAA'를 만들거나 'E'를 여러 번 써서 'EEEEE'를 만들어야 했잖아? 즉, 똑같은 알파벳을 계속 **중복해서 뽑을 수 있어야 했기 때문에** `permutations` 대신 `product`를 사용하는 것이 수학적으로 딱 맞는 접근이었던 거야!
        
      ---

      ### 📝 블로그 포스트 형식

      **[Python] itertools 모듈: permutations와 product의 완벽한 차이 정리**

      알고리즘 문제를 풀며 완전 탐색(Brute-force)을 구현할 때 `itertools` 모듈을 자주 사용하게 됩니다. 그중에서도 가장 혼동하기 쉬운 `permutations`와 `product`의 차이점을 명확히 정리해 보겠습니다.

      **1. permutations (순열)**

        - **특징:** 주어진 데이터에서 요소의 중복을 허용하지 않고 순서대로 뽑아 나열합니다.
        - **수학적 의미:** $n$개의 원소 중 $r$개를 뽑는 순열 (${}_n P_r$)
        - **코드 예시:** `permutations(['A', 'B'], 2)`
        - **실행 결과:** `[('A', 'B'), ('B', 'A')]`
        - **설명:** 원본 배열에 'A'가 하나뿐이므로 'A'를 두 번 연속해서 뽑는('AA') 것이 불가능합니다.

      **2. product (데카르트 곱 / 중복 순열)**

        - **특징:** 단일 객체에서 중복을 허용하여 요소를 뽑거나, 여러 반복 가능한(iterable) 객체들 간의 모든 조합(짝)을 짓습니다.
        - **수학적 의미:** $n$개의 원소 중 중복을 허용해 $r$개를 뽑는 중복 순열 ($n^r$)
        - **코드 예시:** `product(['A', 'B'], repeat=2)`
        - **실행 결과:** `[('A', 'A'), ('A', 'B'), ('B', 'A'), ('B', 'B')]`
        - **설명:** `repeat` 파라미터를 통해 요소를 중복해서 선택할 수 있으므로 'AA'나 'BB' 같은 결과가 생성됩니다. 비밀번호 생성기나 중복이 허용되는 사전(Dictionary) 만들기 문제에 적합합니다.

        ---

      ### 🎙️ 면접 답변 형식

      파이썬의 `permutations`와 `product`의 가장 핵심적인 차이점은 원소 추출 시 중복 허용 여부입니다.

      첫째, `permutations`는 수학적 개념인 '순열'을 구현한 함수입니다. 주어진 컬렉션에서 중복을 배제하고 순서를 고려하여 요소를 추출하기 때문에, 한 번 선택된 요소는 해당 탐색에서 다시 등장할 수 없습니다.

      둘째, `product`는 '데카르트 곱' 또는 '중복 순열'을 의미하며 요소의 중복 추출을 허용합니다. `repeat` 파라미터를 활용하면 같은 요소를 제한 없이 여러 번 선택할 수 있습니다. 따라서 주어진 문자들을 여러 번 재사용해 만들 수 있는 모든 경우의 수를 탐색해야 할 때는 반드시 `product`를 사용해야 올바른 탐색 공간을 구성할 수 있습니다.

      # 

      `요약: permutations는 중복을 허용하지 않는 순열(예: AB, BA)을 생성하고, product는 중복을 허용하는 중복 순열(예: AA, AB, BA, BB)을 생성합니다. 모음 사전처럼 같은 글자가 반복될 수 있는 경우 product를 사용해야 합니다.`

- 참고로 `product`를 사용할 때 `repeat=`은 생략할 수 없다.
    - `repeat=`을 생략할 수 없는 이유.

      서은아, 아주 예리하고 좋은 질문이야! 코드를 짤 때 `range(1, 5)`처럼 파라미터 이름(`start=1, stop=5`)을 생략하는 경우가 워낙 많으니까 당연히 궁금할 수 있는 부분이야.

      결론부터 딱 잘라 말하자면 **`repeat=`은 절대로 생략할 수 없어!** 왜 그런지 파이썬의 입장에서 한 번 설명해 줄게. 파이썬의 `product` 함수는 원래 여러 개의 주머니에서 하나씩 짝을 지어줄 때 쓰는 함수야. 예를 들어 `product(['A', 'B'], ['C', 'D'])`처럼 여러 주머니를 나열해서 쓸 수 있도록 설계되어 있거든.

      그래서 만약 서은이가 코드를 짧게 쓴다고 `product("AEIOU", 3)`이라고 적어버리면, 파이썬은 이렇게 오해해 버려.

      "아하! 첫 번째 주머니는 'AEIOU'고, 짝을 지을 두 번째 주머니는 숫자 3이구나!"

      그런데 숫자 3은 안에서 값을 하나씩 꺼낼 수 있는 리스트나 문자열 같은 주머니(Iterable)가 아니잖아? 그래서 파이썬이 당황하며 `TypeError: 'int' object is not iterable`이라는 에러를 뱉고 기절해 버리는 거지.

      "다른 주머니랑 짝지으려는 게 아니라, 이 'AEIOU' 주머니 하나만 3번 반복해서 중복 순열을 만들 거야!"라고 파이썬에게 정확하게 지시하려면, 반드시 `repeat=3`이라고 파라미터 이름을 콕 집어서 적어줘야만 해.
        
      ---

      ### 📝 블로그 포스트 형식

      **[Python] itertools.product 함수에서 repeat 키워드는 생략이 가능할까?**

      파이썬 내장 모듈인 `itertools`의 `product` 함수를 사용하여 중복 순열을 구할 때, 중복 횟수를 지정하는 `repeat` 인자의 이름을 생략하고 숫자만 넣을 수 있는지 알아보겠습니다.

      결론적으로 **`repeat` 키워드는 생략할 수 없습니다.** 그 이유는 `product` 함수의 매개변수 구조 때문입니다.

      `product` 함수의 공식 문서 원형은 `itertools.product(*iterables, repeat=1)`로 정의되어 있습니다. 여기서 `*iterables`는 가변 위치 인자(Variable Positional Arguments)로, 입력받는 모든 위치 인자를 반복 가능한 객체(Iterable)로 취급하여 데카르트 곱을 수행합니다.

      따라서 `product("AEIOU", 3)`과 같이 키워드를 생략하고 숫자를 넘기게 되면, 파이썬은 숫자 `3`을 두 번째 iterable 객체로 인식합니다. 하지만 정수형(int)은 순회(Iteration)가 불가능한 타입이므로 즉시 `TypeError`가 발생하게 됩니다.

      이러한 에러를 방지하고 동일한 객체를 여러 번 반복하여 조합을 생성하려는 의도를 명확히 하려면, 반드시 `product("AEIOU", repeat=3)`의 형태로 키워드 인자(Keyword Argument)를 명시적으로 전달해야 합니다.
        
      ---

      ### 🎙️ 면접 답변 형식

      **Q. 파이썬의 itertools.product 함수 사용 시, 반복 횟수를 지정하는 repeat 키워드를 생략하면 어떤 문제가 발생하나요?**

      **A.** 타입 에러(TypeError)가 발생하며 프로그램이 정상적으로 동작하지 않습니다.

      첫째, `product` 함수는 설계상 가변 위치 인자인 `*iterables`를 통해 여러 개의 반복 가능한 객체를 입력받도록 되어 있습니다.

      둘째, `repeat` 키워드를 명시하지 않고 정수를 위치 인자로 넘기면, 파이썬 인터프리터는 해당 정수를 데카르트 곱을 수행할 또 다른 '반복 가능한 객체(Iterable)'로 잘못 해석하게 됩니다. 정수형 데이터는 순회할 수 없으므로 즉시 타입 에러를 반환합니다.

      따라서 단일 객체의 중복 순열을 구하려면 반드시 `repeat` 키워드를 명시하여 해당 숫자가 위치 인자가 아닌 키워드 인자임을 명확히 전달해야 합니다.

      # 

      `요약: product 함수는 여러 개의 주머니(Iterable)를 위치 인자로 받도록 설계되어 있습니다. repeat= 을 생략하고 숫자를 적으면, 파이썬이 그 숫자를 새로운 주머니로 착각하여 TypeError를 발생시키므로 반드시 생략 없이 적어주어야 합니다.`


`product`를 사용하지 않고 직접 구현하고 싶다면 다음과 같이 할 수 있다.

```python
def solution(word):
    # 메서드
    def dfs(current_word):
        if len(current_word) == 5:
            return
            
        for v in vowels:
            next_word = current_word + v
            words.append(next_word)
            dfs(next_word)
    
    # 메인 로직
    words = []
    vowels = "AEIOU"
    dfs("")
    
    return words.index(word) + 1
```
