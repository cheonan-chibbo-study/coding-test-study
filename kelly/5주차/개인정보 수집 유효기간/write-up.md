## 👀 제한 시간 안에 어디까지 해냈는가?

제한 시간 `30분` 안에 문제를 풀지 못했다. 문제를 어떻게 풀어야할지 파악하긴해서 코드를 작성했지만 처음에 문제 조건을 잘못 이해해서 테스트 케이스를 성공하지 못했고, 부랴부랴 코드를 수정해서 제출했지만 최종 채점에서 몇몇 케이스를 만족하지 못했다.

아래는 마지막까지 작성한 코드이다.

```python
def solution(today, terms, privacies):
    # 메인 로직
    term_map = {}
    for t in terms:
        t, month = t.split(" ")
        term_map[t] = 28 * int(month) - 1
    
    answer = []
    for i, p in enumerate(privacies):
        start, t = p.split(" ")
        s_y, s_m, s_d = map(int, start.split("."))
        term_day = term_map[t]
        
        n_d = s_d + term_day
        n_m = s_m + (n_d // 28)
        n_y = s_y

        if n_d % 28 == 0:
            n_d = 28
        else:
            n_d = n_d % 28
        
        if n_m > 12:
            n_y = s_y + (n_m // 12)
        
        if n_m % 12 == 0:
            n_m = 12
        else:
            n_m = n_m % 12
        
        if i == 2:
            print(n_y, n_m, n_d)
        c_y, c_m, c_d = map(int, today.split("."))
        if n_y < c_y:
            answer.append(i + 1)
        elif n_y == c_y and n_m < c_m:
            answer.append(i + 1)
        elif n_y == c_y and n_m == c_m and n_d < c_d:
            answer.append(i + 1)
    
    return answer
```

## 🧑‍🔬 문제 분석

오늘 날짜, 약간 종류 리스트, 사용자별 약관 종류와 시작일 리스트가 입력으로 주어졌을 때 유효기간이 종료된 약관 번호 리스트를 반환하는 문제이다.

- 자세한 조건은 문제를 참고하자.

문제에 주어진 제약 조건은 다음과 같다.

### 제한사항

- `today`는 "`YYYY`.`MM`.`DD`" 형태로 오늘 날짜를 나타냅니다.
- 1 ≤ `terms`의 길이 ≤ 20
    - `terms`의 원소는 "`약관 종류` `유효기간`" 형태의 `약관 종류`와 `유효기간`을 공백 하나로 구분한 문자열입니다.
    - `약관 종류`는 `A`~`Z`중 알파벳 대문자 하나이며, `terms` 배열에서 `약관 종류`는 중복되지 않습니다.
    - `유효기간`은 개인정보를 보관할 수 있는 달 수를 나타내는 정수이며, 1 이상 100 이하입니다.
- 1 ≤ `privacies`의 길이 ≤ 100
    - `privacies[i]`는 `i+1`번 개인정보의 수집 일자와 약관 종류를 나타냅니다.
    - `privacies`의 원소는 "`날짜` `약관 종류`" 형태의 `날짜`와 `약관 종류`를 공백 하나로 구분한 문자열입니다.
    - `날짜`는 "`YYYY`.`MM`.`DD`" 형태의 개인정보가 수집된 날짜를 나타내며, `today` 이전의 날짜만 주어집니다.
    - `privacies`의 `약관 종류`는 항상 `terms`에 나타난 `약관 종류`만 주어집니다.
- `today`와 `privacies`에 등장하는 `날짜`의 `YYYY`는 연도, `MM`은 월, `DD`는 일을 나타내며 점(`.`) 하나로 구분되어 있습니다.
    - 2000 ≤ `YYYY` ≤ 2022
    - 1 ≤ `MM` ≤ 12
    - `MM`이 한 자릿수인 경우 앞에 0이 붙습니다.
    - 1 ≤ `DD` ≤ 28
    - `DD`가 한 자릿수인 경우 앞에 0이 붙습니다.
- 파기해야 할 개인정보가 하나 이상 존재하는 입력만 주어집니다.

## 🤔 풀이 고민

### 내가 처음 생각한 풀이

주어진 입력의 크기가 크지 않기 때문에 처음에는 다음과 같이 접근했다.

1. 약관 종류 리스트를 순회해서 약관별 일수 해시 테이블 생성
2. 사용자별 약관 리스트를 순회하면서 약관 종료일을 계산하고 현재 날짜와 비교해서 약관 날짜가 종료된 케이스를 정답 배열에 삽입
3. 정답 배열 반환

다만 처음에 문제 조건을 잘못 이해서서 달 수를 30일로 잡았고, 마지막 1일은 제외해야하는것 등 실수를 많이해서 테스트 케이스에서 오답이 나왔고, 위 실수들을 수정해서 코드를 제출했을 때는 테스트 케이스를 모두 통과시켰지만 최종 제출에서 몇몇 케이스를 실패했다.

더 좋은 풀이가 있을거 같아서 다른 풀이를 찾아봤다.

### 찾아본 풀이

`today`로 제시된 날짜를 기준으로 `privacies`에 담긴 개인 정보 수집 일자와 약관 종류로 결정된 유효기간 마지막 날짜가 지났는지, 지나가지 않았는지를 판단해야한다.

인간 친화적인 연월일 형식으로 비교하는 것은 자릿수 계산을 해야해서 복잡해진다. 이때 연월일 형식을 최소 단위인 일수로 통일하면 계산이 편해진다.

- (만약, 시:분:초 문제였다면 최소단위인 ‘초’에 맞추면 계산이 편해진다.)

우선 해시테이블을 사용하여, 다음과 같이 설정한다.

- key: `모든 약관의 종류`
- value : `약관 유효 기간(일단위)`

`privacies`를 순회하며, `today` 와 개인정보 수집 일자 사이의 기간과 약관 종류에 따른 개인정보 수집 일자부터 유효 기간 종료 일자 사이의 기간을 일수로 계산해서 각 결과값을 비교한다.

만약 유효 기간 종료 일자까지의 기간보다 `today` 까지 남은 일수가 더 많다면, 개인정보 수집 유효 기간이 만료되었으므로 반환할 리스트에 현재 개인정보에 해당하는 인덱스에 1을 더하여 저장한다.

2000 ≤ `YYYY` ≤ 2022 이기때문에 값이 너무 커지지 않게 연도를 일수로 바꿀 때 2000을 빼줘도 좋다.

- 어느정도 아이디어를 떠올려야 하는 구현 문제이다.

## 🏃 코드 작성 과정

### 찾아본 풀이로 작성한 코드

따로 찾아본 풀이를 코드로 구현하면 다음과 같다.

```python
def solution(today, terms, privacies):
    # 메서드
    # ✅ 해시테이블에 약관별 유효기간을 일수로 계산해 저장한다.
    def calc_due(time):
        return ((time[0] - 2000) * 12 * 28) + ((time[1] - 1) * 28) + (time[2] - 1)
    
    # 메인 로직
    answer = []
    term_dict = {}
    for t in terms:
        name, term = t.split()
        term_dict[name] = int(term) * 28
    
    today = [int(i) for i in today.split(".")]
    today_due = calc_due(today)
    
    for idx, p in enumerate(privacies):
        start, name = p.split()
        start = [int(i) for i in start.split(".")]
        cur_due = calc_due(start)
        
        # ✅ 개인정보 수집일로부터 며칠이 지났는지 구한다.
        # ✅ 약관 유효기간보다 오래됐다면 인덱스를 정답 리스트에 추가한다.
        if term_dict[name] <= today_due - cur_due:
            answer.append(idx + 1)
    
    return answer
            
```
