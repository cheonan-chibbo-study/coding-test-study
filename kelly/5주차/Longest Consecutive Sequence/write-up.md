## 👀 제한 시간 안에 어디까지 해냈는가?

5주차 첫 문제이기 때문에 학습을 위해 따로 제한 시간을 두지 않고 풀었다.

결론적으로 혼자서 문제를 풀지 못해 풀이를 찾아보았다. 찾아본 풀이로 작성한 코드를 복기하면서 해시 테이블 or 해시 셋의 활용 사례를 체화할 필요가 있다.

---

## 🧑‍🔬 문제 분석

정렬되지 않은 정수 리스트가 주어졌을 때, 가장 길게 연속되는 순열의 길이를 반환하는 문제이다.

- 추가로 이 문제는 `O(N)`의 알고리즘으로 풀도록 강제하고 있다.

문제에 주어지는 조건은 다음과 같다.

**Constraints:**

- `0 <= nums.length <= 105`
- `109 <= nums[i] <= 109`

---

## 🤔 풀이 고민

문제를 처음 풀 때 혼자서 풀이를 떠올리지 못했다. 아래는 찾아본 풀이를 정리한 내용이다.

이 문제에서는 한 숫자의 연속된 다음 숫자를 찾는 탐색의 과정에서 소요되는 시간복잡도를 줄이는 것이 관건이다.

원소를 리스트에 저장한 상태에서 탐색을 하는 것은 O($n$)의 시간 복잡도를 가지며 모든 원소에 대해 연속된 수를 찾는 과정은 O($n^2$)의 시간 복잡도를 갖는다. 이는 문제에서 요구하는 전체 시간 복잡도 O($n$)을 초과하게 된다.

즉 문제에서 요구하는 시간 복잡도를 충족하기 위해서는 O(1)의 시간 복잡도를 갖는 자료구조를 사용해야 될 필요가 있다. 해시테이블은 key값으로, 특정 값에 대해 해시값을 구하고 이를 저장하는 자료구조이기 때문에 주어진 key값에 대한 임의 접근(random access)이 가능하다. 그렇기에 주어진 key값이 해시테이블에 존재하는지 탐색하는 시간 복잡도는 O(1)이며 이를 모든 원소에 대해 진행하게 될 경우 O($n$)으로 문제에서 요구하는 시간 복잡도를 충족할 수 있게 된다.

연속되는 숫자 시퀀스의 최대 길이를 확인하기 위해 시퀀스의 첫 숫자부터 1씩 증가시켜가며 해시테이블에 존재하는지 확인한다. 이 때 시퀀스의 중간에서부터 탐색을 시작한다면 해당 시퀀스의 길이를 제대로 확인할 수 없다.

따라서 시퀀스의 첫 숫자를 구하기 위해 해시테이블에 저장된 수 중 자신의 이전값이 해시테이블에 포함되지 않는 수를 통해 탐색을 진행한다.

이 문제의 경우 해시테이블의 key값을 사용하는 것이기 때문에, hashset을 사용해도 동일한 결과를 알 수 있다.

### 결론

- Hash Table or Hash Set을 활용해 `O(N)`의 시간으로 문제를 해결할 수 있다.

## 🏃 코드 작성 과정

### 구현하지 못한 부분 구현

위에 기술한 풀이를 코드로 구현하면 다음과 같다. 코드는 Hash Table을 사용한 코드와 Hash Set을 사용한 코드를 각각 작성했다.

[ Hash Table을 사용해서 구현 ]

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 메인 로직
        answer = 0

        #✅ 각 숫자를 key값으로 하여 해시테이블을 만든다.
        num_dict = {}
        for num in nums:
            num_dict[num] = True
        
        #✅ 해시테이블을 순회한다.
        for num in num_dict:
            #✅ 만약 이전 숫자가 존재하지 않는다면, 개수를 1로 초기화한다.
            if num - 1 not in num_dict:
                cnt = 1
                target = num + 1

                #✅ 다음 숫자가 존재할 때까지 개수를 1씩 증가시킨다.
				#✅ 연속된 숫자 개수 최댓값을 업데이트한다.
                while target in num_dict:
                    target += 1
                    cnt += 1

                answer = max(answer, cnt)

        return answer
```

[ Hash Set을 사용해서 구현 ]

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 메인 로직
        answer = 0
        num_set = set(nums)

        for num in num_set:
            if num - 1 not in num_set:
                cnt = 1
                target = num + 1

                while target in num_set:
                    target += 1
                    cnt += 1
                
                answer = max(answer, cnt)

        return answer
```

- 참고로 위 코드를 `for num in nums:`로 작성하면 시간 초과가 발생한다. 중복된 정수에 대해서도 모두 탐색을 진행하기 때문이다.

## 🥰 배운점 & 느낀점

- Hash Table과 Hash Set을 이렇게 활용할 수도 있구나라는걸 배웠다. 이렇게 문제에서 대놓고 시간 복잡도를 강제하는 문제라면 시간 복잡도를 낮출 수 있는 방법을 고민해야 하는데 좋은 사례가 될 거 같다. 꼭 복습해서 비슷한 문제를 만나면 잘 써먹자!!!
