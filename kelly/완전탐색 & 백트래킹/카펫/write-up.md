## 👀 제한 시간 안에 어디까지 해냈는가?

제한 시간내 문제 풀이법도 떠올리지 못했다. 혼자서 풀 수 있는 문제가 아니라는 생각이 들어 빠르게 풀이를 찾아봤다.

- 그리고 솔직히 풀이를 보고도 어떻게 저런 공식이 도출되는건지 이해가 되지 않아 제미나이와 함께 살펴봤다.

P & J 트레이닝

- 혼자서 문제를 해결하지 못했다.
    - 어찌어찌 코드를 작성하여 테스트 케이스는 모두 맞았지만 최종 제출에서 정확도 76.9로 문제를 통과하지 못했다.
    - 작성한 코드

        ```python
        def solution(brown, yellow):
            for col in range(2, brown):
                for row in range(2, col + 1):
                    if (col * row) - yellow == brown:
                        return [col, row]
        ```

- 결과적으로 내가 작성한 코드는 몇몇 예외 사항을 잡지 못하기 때문에 통과하지 못했다.
- 이 문제는 생각보다 엣지 케이스를 잘 따져야 풀 수 있는 문제이다. 제법 좋은 문제니 잘 복습해서 다음번에는 꼭 한번에 풀 수 있도록 연습하자.

## 🧑‍🔬 문제 분석

카펫을 구성하는 brown 영역의 개수와 yellow 영역의 개수가 주어졌을 때 전체 카펫의 너비와 높이를 구해 배열 형태로 반환하는 문제이다.

문제에 주어지는 조건은 다음과 같다.

### 제한사항

- 갈색 격자의 수 brown은 8 이상 5,000 이하인 자연수입니다.
- 노란색 격자의 수 yellow는 1 이상 2,000,000 이하인 자연수입니다.
- 카펫의 가로 길이는 세로 길이와 같거나, 세로 길이보다 깁니다.

## 🤔 풀이 고민

### 찾아본 풀이

문제 풀이는 아래 유튜브 영상을 참고했다. 설명을 굉장히 잘해준다.

프로그래머스 - 카펫

우선 카펫의 전체 넓이를 구하는건 어렵지 않다. 카펫의 전체 넓이를 `area`라고 가정하면, `area`는 다음과 같다.

- `area` = yellow + brown

그리고 yellow 전체 개수를 연결 지을 수 있는 공식은 다음과 같다고 하는데 솔직히 이 공식이 어떻게 도출된건지 전혀 이해가 되지 않아 제미나이에게 물어봤다. 우선 공식을 나열하면 다음과 같다.

- 카펫의 너비, 높이를 w, h라고 할 때
- yellow의 개수는 (w - 2) * (h - 2)
- 이 공식이 어떻게 도출된건지 이해가 되지 않아 제미나이에게 물어봤다.
    - 🤖 제미나이 답변

      ## 블로그 포스트 스타일

      서은아, 아스키 아트(ASCII Art)로 직접 그려서 보니까 훨씬 아이디어가 좋네! 눈으로 직접 격자를 세어보면 공식이 어떻게 나왔는지 단번에 이해가 될 거야. 쌤이랑 귀여운 미니 카펫을 하나 만들어보자.

      가로 길이(`w`)가 4, 세로 길이(`h`)가 3인 카펫이 있다고 상상해 볼게.

      갈색 타일은 `B` (Brown), 노란색 타일은 `Y` (Yellow)라고 표시할게!

      Plaintext

      # 

      `[전체 카펫의 모습: w=4, h=3]
      B B B B  (맨 윗줄)
      B Y Y B  (가운데 줄)
      B B B B  (맨 아랫줄)`

      First, **가로 길이(`w`)에서 왜 2를 빼는지 눈으로 확인해 볼까?**

      가운데 줄을 쭉 읽어보면 `B Y Y B` 이렇게 총 4칸(`w`)으로 이루어져 있어.

      여기서 우리가 알고 싶은 건 순수한 노란색(`Y`)의 가로 길이잖아? 그러려면 제일 왼쪽에 덮인 갈색 타일(`B`) 1칸과, 제일 오른쪽에 덮인 갈색 타일(`B`) 1칸, 이렇게 총 2칸을 덜어내야 해.

      결과적으로 노란색의 가로 길이는 `w - 2`, 즉 4 - 2 = 2칸이 되는 거야!

      Second, **세로 길이(`h`)에서 왜 2를 빼는지도 확인해 보자.**

      이번엔 위에서 아래로 떨어지는 두 번째 세로줄을 읽어볼게. `B` (위), `Y` (가운데), `B` (아래) 이렇게 총 3칸(`h`)이지?

      노란색(`Y`)만의 세로 길이를 구하려면, 역시나 지붕 역할을 하는 맨 위 갈색 타일(`B`) 1칸과 바닥 역할을 하는 맨 아래 갈색 타일(`B`) 1칸, 총 2칸을 위아래로 덜어내야 해.

      결과적으로 노란색의 세로 길이는 `h - 2`, 즉 3 - 2 = 1칸이 되는 거란다!

      Third, **두 값을 곱해서 직사각형의 넓이를 증명해 보자.**

      노란색 격자들만 따로 떼어내서 보면, 가로가 2칸, 세로가 1칸인 작고 귀여운 직사각형 모양(`Y Y`)이 돼.

      넓이는 '가로 x 세로'니까, `(w - 2) * (h - 2)`를 계산하면 2 * 1 = 2가 나오지?

      아스키 아트 정중앙에 있는 `Y`의 개수(2개)와 정확하게 일치하는 걸 볼 수 있어!

      이렇게 격자를 그려서 테두리(양옆 2칸, 위아래 2칸)를 깎아내는 상상을 해보면, 왜 하필 1도 아니고 3도 아닌 '2'를 빼야만 했는지 아주 직관적으로 와닿을 거야.

      ## 면접 답변 스타일

      First, 문제의 기하학적 구조를 아스키 아트로 시각화하면, `B`를 테두리, `Y`를 내부 격자라고 할 때 `B B B B` / `B Y Y B` / `B B B B` (w=4, h=3)의 형태를 띠게 됩니다.

      Second, 이 구조에서 내부 노란색 영역(`Y`)의 순수 너비를 구하기 위해서는 전체 너비 `w`에서 좌측과 우측의 `B` 격자를 각각 1칸씩 배제해야 하므로 `w - 2`가 도출됩니다. 마찬가지로 순수 높이를 구하기 위해서는 전체 높이 `h`에서 상단과 하단의 `B` 격자를 1칸씩 배제해야 하므로 `h - 2`가 도출됩니다.

      Third, 결과적으로 도출된 내부 영역의 가로 길이(`w - 2`)와 세로 길이(`h - 2`)를 곱하여 직사각형의 넓이를 구하면, 그것이 곧 중앙에 위치한 노란색 격자(`Y`)의 총 개수와 정확히 일치한다는 것을 시각적, 논리적으로 증명할 수 있습니다.

      Plaintext

      # 

      `아스키 아트 시각화를 통해, 전체 격자에서 좌우 테두리 1칸씩(-2)과 상하 테두리 1칸씩(-2)을 제외했을 때 순수한 내부 격자의 가로 및 세로 길이가 도출됨을 직관적으로 확인 및 증명 완료.`


카펫의 높이 h는 3 ~ int(area ** 0.5)의 범위를 가진다.

- 문제 조건을 보면 yellow의 최소 값은 1이므로 h와 w는 최소 3이 되어야한다.
    - 그래야 (3 - 1) * (3 - 1) == 1이 되기 때문
- 카펫의 높이는 넓이보다 작거나 같기 때문에 h는 아무리 커도 area의 제곱근까지만 크기를 가질 수 있다.

위 공식이 이해되었다면 문제 풀이를 정리해보자.

1. yellow + brown으로 전체 카펫의 넓이 area를 구한다.
2. h를 기준으로 3 ~ area의 제곱근까지 반복문을 수행하면서 h에 대응되는 w를 구한다.
3. (w - 2) * (h - 2) == yellow에 대응되는 w와 h를 찾아 반환한다.

### 결론

- 이 문제는 기하학 센스와 수학적 센스가 있어야 풀이를 떠올릴 수 있다.
- 위 풀이를 코드로 구현하면 문제를 해결할 수 있다.

## 🏃 코드 작성 과정

### 찾아본 풀이로 작성한 코드

```python
def solution(brown, yellow):
    area = brown + yellow
    for h in range(3, int(area ** 0.5) + 1):
        if area % h == 0:
            w = area // h
            if (w - 2) * (h - 2) == yellow:
                return [w, h]
```

### Java 풀이

- solution01

    ```java
    class Solution {
        public int[] solution(int brown, int yellow) {
            int area = brown + yellow;
            
            for (int h = 3; h <= (int) Math.pow(area, 0.5); h++) {
                if (area % h != 0) {
                    continue;
                }
                
                int w = area / h;
                if ((w - 2) * (h - 2) == yellow) {
                    return new int[]{w, h};
                }
            }
            
            return new int[]{-1, -1};
        }
    }
    ```
