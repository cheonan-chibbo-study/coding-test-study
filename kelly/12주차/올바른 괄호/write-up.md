## 👀 제한 시간 안에 어디까지 해냈는가?

`3분 49초`만에 문제를 해결했다.

---

## 🧑‍🔬 문제 분석

`(`, `)`로 구성된 문자열이 주어졌을 때 괄호쌍이 모두 맞는지 여부를 반환하는 문제이다.

문제에 주어진 제약 조건은 다음과 같다.

### 제한사항

- 문자열 s의 길이 : 100,000 이하의 자연수
- 문자열 s는 '(' 또는 ')' 로만 이루어져 있습니다.

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

너무 간단한 Stack 연습 문제이다. Stack을 활용해 괄호쌍 일치 여부를 검사하도록 코드를 작성하면 문제를 해결할 수 있다.

- 진짜 stack 기본 연습 문제다.

---

## 🏃 코드 작성 과정

### 내가 처음 작성한 코드

```python
def solution(s):
    stack = []
    for ch in s:
        if ch == "(":
            stack.append(")")
            continue
        
        if not stack:
            return False
        
        stack.pop()
    
    return not stack
```
