## 👀 제한 시간 안에 어디까지 해냈는가?

제한 시간 `30분`안에 문제를 풀지 못했다. 아예 풀이법 자체도 떠올리지 못했다.

---

## 🧑‍🔬 문제 분석

0, 1로 이루어진 격자 정보가 주어졌을 때 내부가 모두 1로 이루어진 정사각형 중 가장 넓은 정사각형의 넓이를 반환하는 문제이다.

문제에 주어지는 제약 조건은 다음과 같다.

**Constraints:**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 300`
- `matrix[i][j]` is `'0'` or `'1'`.

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

우선 완탐으로는 이 문제를 해결할 수 없을거라 생각했다. 각 요소를 순회하면서 정사각형 영역을 검사한다고 가정하면 시간 복잡도가 대략 다음과 같이 발생한다.

- `O(M^N^)`

입력될 수 있는 격자의 최대 크기가 300이므로 위 방식으로는 문제를 해결할 수 없다.

그럼 결국 이 문제를 해결하는 방법 중 하나가 DP라는 의미이기 때문에 DP의 조건을 만족하는지 살펴봤고, 특정 정사각형의 크기를 구하는데 그 내부에 이미 계산된 정사각형의 크기를 활용할 수 있다는 생각이 들어 분명 점화식을 설계할 수 있을거라는 생각이 들었다.

하지만 혼자 힘으로는 구체적인 점화식을 설계하지 못하여 결국 다른 사람의 풀이를 찾아봤다.

- 다른 사람의 점화식 설계를 살펴봤는데 생각보다 너무 간단하고 기똥차서 허무했다…

주어진 `matrix` 에서 1로만 이루어진 정사각형 중 가장 큰 넓이를 가지는 정사각형을 찾아야한다. 정사각형을 확인하는 방법은 `"1"` 이 들어있는 칸으로부터 한 변의 길이를 늘리면서 현재 크기의 정사각형에 해당하는 영역이 모두 `"1"` 로 이루어져 있는지 확인한다.

가장 첫 번째로 시도해볼 수 있는 방법은 모든 칸을 순회하며 `"1"` 이 들어있는 칸을 시작으로 만들 수 있는 정사각형의 넓이를 구해보는 것이다. 즉, 부르트 포스(Brute Force) 방식으로 모든 정사각형의 크기를 확인해보는 것이다.

하지만, 이 경우, 불필요한 경우가 발생한다. 만약 현재까지 계산된 정사각형의 최대 크기는 $3\times3=9$ 라고 하면, 한 변의 길이가 3이 될 수밖에 없는 영역에 대해서는 더 이상 정사각형의 크기를 조사해 볼 필요가 없다.

즉, 기존 부르트 포스 방식을 개선해서 다음과 같이 탐색 유효 범위를 설정할 수 있다.

![개선된 부르트 포스(Brute Force)](attachment:55d4f9f8-ae88-42f2-a893-8345f3f2a8a4:Untitled.png)

개선된 부르트 포스(Brute Force)

하지만 이 방식도 최대 크기의 정사각형을 찾기 위해서 1칸씩 `"1"` 이 존재하는지 확인해야하기 때문에 소요가 발생한다.

**[ 풀이 최적화 ]**

이 과정을 정사각형의 구조를 이용해서 최적화할 수 있다.

- 정사각형은 아래와 같이 더 작은 정사각형을 반드시 포함하고 있다. 이 정보를 통해 DP를 이용해서 최대 크기의 정사각형을 구할 수 있다.

![Untitled](attachment:8b6abf98-b1dc-4b8d-bd82-9c130170f924:Untitled.png)

우선 현재 `"1"` 이 존재하는 칸을 A라고 하자. 그리고 이 칸을 최대 정사각형의 우측 하단 위치로 간주한다. 현재 위치(A)에서 왼쪽 칸, 왼쪽 윗칸, 윗칸에는 해당 칸에서 만들어질 수 있는 최대 정사각형 크기의 한 변의 길이가 담겨있다. 그 때, A에 들어갈 값은 왼쪽 칸, 왼쪽 윗칸, 윗칸에 들어있는 값에서 1을 더한 값이다. 왜냐하면, 이전 칸(왼쪽 칸, 왼쪽 윗칸, 윗칸)에서 길이를 1 증가시켜서 만들 수 있는 최대 크기의 정사각형을 계산할 수 있기 때문이다. 이 과정은 Bottom-up 유형에 해당한다. 점화식은 다음과 같다.

$$
F(r, c)=\mathrm{min}(F(r, c-1), F(r-1, c-1), F(r-1, c))_{\mathrm{matrix}[r][c] = 1} + 1\\F(1,1)=1
$$

모든 칸에서 최대 크기의 정사각형을 계산해야하기 때문에 `matrix` 의 맨 왼쪽 끝단과 상단을 1줄 늘리고, 0으로 초기화한 후, DP를 진행한다. 다음 그림의 과정을 참고해보자.

### 결론

- 위 풀이에 기술한 점화식을 활용하면 DP 방식으로 문제를 해결할 수 있다.
- 풀이를 구현하는 방법은 여러가지가 있을 수 있다. 찾아본 풀이는 가장 자리를 0으로 확장하는 방법을 사용했지만 난 그냥 처음부터 가장자리를 초기화하는 방법이 나은거 같다.

## 🏃 코드 작성 과정

### 찾아본 풀이로 작성한 코드

위 풀이를 코드로 구현하면 다음과 같다.

- 점화식이 명확한 문제라 굳이 top-down으로 코드를 작성할 필요는 없어서 bottom-up으로만 구현했다.

```python
class Solution:
    def maximalSquare(self, matrix: List[List[str]]) -> int:
        # 전역 데이터
        M = len(matrix)
        N = len(matrix[0])
        matrix = [[int(c) for c in r] for r in matrix]
        dp = [[0] * N for _ in range(M)]

        for r in range(0, M):
            if matrix[r][0] == 1:
                dp[r][0] = 1

        for c in range(0, N):
            if matrix[0][c] == 1:
                dp[0][c] = 1
        
        # 메인 로직
        for r in range(1, M):
            for c in range(1, N):
                if matrix[r][c] == 1:
                    dp[r][c] = min(dp[r][c - 1], dp[r - 1][c - 1], dp[r - 1][c]) + 1
        
        return max(max(r) for r in dp) ** 2
```
