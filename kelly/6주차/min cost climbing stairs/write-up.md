## 👀 제한 시간 안에 어디까지 해냈는가?

`DP` 학습을 위한 문제였기 때문에 따로 제한 시간을 걸지 않고 풀었다.

---

## 🧑‍🔬 문제 분석

계단별 이동 비용 리스트가 주어졌을 때 한 칸 혹은 두 칸 이동할 경우 계단을 모두 오를 수 있는 최소 비용을 구해서 반환하는 문제이다.

- 자세한 조건은 문제를 참고하자.

문제에 주어진 제약 조건은 다음과 같다.

**Constraints:**

- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

이 문제는 아이디어 자체를 떠올리지 못해 결국 풀이를 찾아봤다.

### 찾아본 풀이

문제에서 계단은 한 번에 한 칸 또는 두 칸을 올라갈 수 있다고 명시되어 있다. 즉 n번째 계단에 도달하는 경우의 수는 n-1번째 계단에서 한 칸을 올라가는 경우의 수와 n-2번째 계단에서 두 칸을 올라가는 경우의 수 두 가지이다.

이 때 각 계단을 오를 때는 해당 계단에 해당하는 만큼의 비용이 소요된다. 또한 문제에서 요구하는 값은 비용의 최소값이므로 다음과 같은 점화식을 구할 수 있다.

$$
F(n) = \mathrm{min}(F(n-1)+\mathrm{cost}(n-1),\ F(n-2)+\mathrm{cost}(n-2))\\F(0) = 0\\F(1) = 0
$$

해당 점화식을 통해 top-down, bottom-up방식으로 코드를 구현할 수 있는데 이 때 중복되는 값을 구하는 소요가 생기며 이를 memoization을 통한 중복 제거로 최적화 할 수 있다.

위 점화식이 이해가 가지 않아서 GPT에게 추가적인 설명을 부탁했다.

- GPT 설명

  Kelly가 헷갈린 이유는 **이 문제에서 “비용을 언제 내는지”와 “TOP이 무엇인지”**를 정확히 구분하지 않았기 때문입니다.

  이 문제는 **마지막 계단(n)** 이 **실제 계단이 아닙니다.**

  즉

  TOP = 배열 밖 (cost 없음)

  입니다.

  이게 핵심입니다.
    
  ---

  # 1️⃣ 계단 구조 먼저 정확히 보기

  예를 들어

  cost = [10, 15, 20]

  이면 실제 계단은

  index   cost
  0       10
  1       15
  2       20
  TOP

  입니다.

  즉

  TOP에는 cost가 없다

  그래서

  마지막에 cost[n] 같은 것은 존재하지 않는다
    
  ---

  # 2️⃣ 비용은 언제 내는가?

  문제 규칙

  계단 i 를 "밟을 때" cost[i]를 낸다

  즉

  계단을 떠날 때 X

  계단을 밟을 때 O

  입니다.
    
  ---

  # 3️⃣ 점화식이 왜 이렇게 되는가

  점화식

  F(n) = min(F(n-1)+cost(n-1), F(n-2)+cost(n-2))

  여기서

  F(n) = TOP에 도착하는 최소 비용

  입니다.

  TOP에 오기 직전 위치는

  n-1

  또는

  n-2

  뿐입니다.
    
  ---

  # 4️⃣ 두 경우를 나눠보자

  ## 경우 1️⃣ n-1 → TOP

  ... → n-1 → TOP

  여기서 우리는

  n-1 계단을 밟았다

  그래서 비용

  F(n-1) + cost(n-1)

  입니다.
    
  ---

  ## 경우 2️⃣ n-2 → TOP

  ... → n-2 → TOP

  2칸 점프

  여기서

  n-1은 밟지 않는다

  n도 밟지 않는다

  그래서

  cost(n-2)까지만 낸다

  즉

  F(n-2) + cost(n-2)

  입니다.
    
  ---

  # 5️⃣ Kelly가 헷갈린 부분

  Kelly 생각

  n-2 → n

  그래서

  cost(n)도 내야 하는 것 아닌가?

  하지만

  n은 계단이 아니라 TOP이다

  그래서

  cost(n) 자체가 존재하지 않는다
    
  ---

  # 6️⃣ 실제 예시로 계산

  cost = [10,15,20]

  TOP index = 3

  ### F(2)

  min(
  F(1)+cost[1],
  F(0)+cost[0]
  )

  min(0+15, 0+10)
  = 10
    
  ---

  ### F(3) (TOP)

  min(
  F(2)+cost[2],
  F(1)+cost[1]
  )

  min(10+20, 0+15)
  = 15

  그래서 답

  15
    
  ---

  # 7️⃣ 그림으로 보면 더 쉬움

  0(10)   1(15)   2(20)   TOP

  가능한 경로

  1 → TOP = 15

  0 → 1 → TOP = 25

  0 → 2 → TOP = 30

  최소

  15
    
  ---

  # 8️⃣ 한 줄 핵심

  Kelly가 착각한 부분

  n은 계단이라고 생각함

  하지만 실제 문제는

  n = TOP (계단 아님)

  그래서

  cost[n] 은 존재하지 않는다
    
  ---

  # 9️⃣ 이 문제를 더 쉽게 보는 방법

  이 문제는 사실 이렇게 생각하면 됩니다.

  각 계단을 떠나는 비용 문제

  그래서 점화식이

  dp[i] = cost[i] + min(dp[i-1], dp[i-2])

  형태로도 많이 풉니다.


### 결론

- DP를 활용해 top-down & bottom-up 방식으로 문제를 해결할 수 있다.

## 🏃 코드 작성 과정

### 찾아본 풀이로 작성한 코드

위 풀이를 코드로 작성하면 다음과 같다.

**[ top-down ]**

```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        # 전역 데이터
        costs = {0: 0, 1: 0}
        
        # 메서드
        def dp(n):
            if n not in costs:
                costs[n] = min(dp(n - 1) + cost[n - 1], dp(n - 2) + cost[n - 2])
            
            return costs[n]

        # 메인 로직
        return dp(len(cost))
```

**[ bottom-up ]**

```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        # 전역 데이터
        n = len(cost)

        costs = [-1] * (n + 1)
        costs[0] = 0
        costs[1] = 0

        # 메인 로직
        for i in range(2, n + 1):
            costs[i] = min(costs[i - 1] + cost[i - 1], costs[i - 2] + cost[i - 2])
        
        return costs[n]
```
