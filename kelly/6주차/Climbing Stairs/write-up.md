## 👀 제한 시간 안에 어디까지 해냈는가?

`DP` 학습을 위한 문제였기 때문에 따로 제한 시간을 걸지 않고 풀었다.

---

## 🧑‍🔬 문제 분석

정수 n이 주어졌을 때 1 걸음 혹은 2걸음 단위로 이동하면 목적지 n에 도달하기까지 수행할 수 있는 이동 과정의 개수를 모두 구해서 반환하는 문제이다.

- 자세한 조건은 문제를 참고하자.

문제에 주어진 제약 조건은 다음과 같다.

**Constraints:**

- `1 <= n <= 45`

---

## 🤔 풀이 고민

### 혼자서 생각해낸 풀이

우선 문제 자체는 재귀를 활용한 완전 탐색으로 구현이 가능해서 아래와 같이 재귀 완탐 코드를 작성하고 제출해봤다.

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 메서드
        def search(n, temp, total):
            if n == 0:
                total.append(temp[:])
                return

            for i in range(1, 3):
                if n < i:
                    continue
                temp.append(i)
                search(n - i, temp, total)
                temp.pop()

        # 메인 로직
        total = []
        search(n, [], total)

        return len(total)
```

이 코드는 테스트 케이스를 통과하지만 최종 제출에서는 메모리 초과로 실패한다. 아무래도 완전 탐색 방식으로 모든 경우의 수를 쌓아가기에는 너무 경우가 많은게 문제인거 같다.

따라서 이 문제는 중복된 부분을 제거하는 DP로 접근해야겠다고 생각하고 하위 문제를 나눠 중복되는 구간을 찾아보려고 했지만 좀처럼 아이디어가 떠오르지 않았다. 그래서 결국 다른 사람의 풀이를 찾아봤다.

### 찾아본 풀이

문제에서 계단은 한 번에 한 칸 또는 두 칸을 올라갈 수 있다고 명시되어 있다. 즉 n번째 계단에 도달하는 경우의 수는 n-1번째 계단에서 한 칸을 올라가는 경우의 수와 n-2번째 계단에서 두 칸을 올라가는 경우의 수 두 가지이다.

그렇기에 다음과 같은 점화식을 유도할 수 있다.

$$
F(n) = F(n-1) + F(n-2)\\F(0) = 1\\F(1) = 1
$$

해당 점화식을 통해 top-down, bottom-up방식으로 코드를 구현할 수 있는데 이 때 중복되는 값을 구하는 소요가 생기며 이를 memoization을 통한 중복 제거로 최적화 할 수 있다.

참고로 0번째가 1인 이유는 “아무 것도 하지 않는 방법”으로 1개가 있기 때문이다.

풀이가 쉽게 이해가지 않아서 GPT한테도 풀이를 부탁했다.

- GPT 답변

  Kelly가 헷갈린 지점이 DP에서 가장 많이 헷갈리는 부분이라서 아주 좋은 질문입니다.
  결론부터 말하면 "2를 더하는 것이 아니라 이미 경우의 수 안에 포함되어 있다" 입니다.

  핵심은 이것입니다.

  우리는 마지막 이동까지 포함된 전체 경우의 수를 세고 있습니다.
  그래서 +2를 하는 것이 아니라 + (경우의 수)를 하는 것입니다.

  1️⃣ 먼저 정확한 값부터 확인

  계단 문제에서

  dp(1) = 1
  dp(2) = 2
  dp(3) = 3
  dp(4) = 5
  dp(5) = 8

  Kelly가 가정한 값

  n=4 -> 3가지
  n=3 -> 2가지

  이건 실제 값이 아니라 예시로 만든 값입니다.

  실제 값은

  dp(4) = 5
  dp(3) = 3

  그래서

  dp(5) = 5 + 3 = 8

  입니다.

  2️⃣ 실제로 전부 써보면 이해가 됩니다 (n = 5)

  가능한 모든 경우

  1 1 1 1 1
  1 1 1 2
  1 1 2 1
  1 2 1 1
  2 1 1 1
  1 2 2
  2 1 2
  2 2 1

  총 8가지

  3️⃣ 마지막 이동 기준으로 나누기

  마지막에 1칸 올라온 경우

  즉

  4 → 5

  그러면 4까지 오는 모든 방법 뒤에 1을 붙입니다.

  4까지 오는 방법

  1 1 1 1
  1 1 2
  1 2 1
  2 1 1
  2 2

  뒤에 +1

  1 1 1 1 1
  1 1 2 1
  1 2 1 1
  2 1 1 1
  2 2 1

  총 5개

  즉

  dp(4) = 5

  마지막에 2칸 올라온 경우

  즉

  3 → 5

  3까지 오는 방법

  1 1 1
  1 2
  2 1

  뒤에 +2

  1 1 1 2
  1 2 2
  2 1 2

  총 3개

  즉

  dp(3) = 3

  4️⃣ 그래서 합치면

  5 + 3 = 8

  즉

  dp(5) = dp(4) + dp(3)

  입니다.

  5️⃣ Kelly가 헷갈린 부분

  Kelly 생각

  3 -> 4까지 오는 방법 개수
  2 -> 3까지 오는 방법 개수

  그리고 1칸 또는 2칸 가야 하니까
  +2 해야 하나?

  하지만 그 1칸 / 2칸 이동은 이미 경우의 수 안에 포함됩니다.

  예를 들어

  1 1 2

  이게 3까지 오는 방법이라면

  1 1 2 + 2

  이렇게 해서 5까지 오는 방법 하나가 됩니다.

  즉

  각 경우가 이미 마지막 이동을 하나씩 만들어냅니다.

  그래서

  +2

  를 하는 것이 아니라

  경우의 수 × 1

  이 되는 것입니다.

  6️⃣ 한 줄 핵심

  DP에서

  dp(n) = dp(n-1) + dp(n-2)

  의 의미는

  n-1까지 오는 모든 방법 뒤에 1을 붙인다
    +
  n-2까지 오는 모든 방법 뒤에 2를 붙인다

  입니다.


### 결론

- DP를 활용해 top-down, bottom-up 방식으로 문제를 해결할 수 있다.

## 🏃 코드 작성 과정

### 찾아본 풀이로 작성한 코드

위에서 찾아본 풀이를 코드로 구현하면 각각 다음과 같다.

**[ top-down ]**

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 전역 데이터
        # ✅ 목표 계단 수(n) 크기의 memo를 만들고 -1로 초기화한다.
        memo = [None] * (n + 1)

        # 메서드
        def dp(n):
            # ✅ 현재 계단 순서(n)가 0번째 혹은 1번째일 경우, 1을 반환한다. (base case)
            if n == 0 or n == 1:
                return 1

            # ✅ 현재 계단(n)에 도달하는 가짓수가 지정되어있지 않다면, (None)
            if not memo[n]:
                #✅ n-1번째, n-2번째 계단에 대하여 재귀함수를 호출한다. (recurrence relation)
                memo[n] = dp(n - 1) + dp(n - 2)
            
            #✅ 현재 계단(n)에 도달하는 총 가짓수를 반환한다.
            return memo[n]

        # 메인 로직
        return dp(n)
```

**[ bottom-up ]**

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        dp = [None] * (n + 1)
        dp[0] = 1
        dp[1] = 1

        #✅ 2번째 계단부터 n번째 계단까지 올라간다.
        for i in range(2, n + 1):
            #✅ 점화식에 따라 각 계단에 도달할 수 있는 총 가짓수를 구한다.
            dp[i] = dp[i - 1] + dp[i - 2]
        
        #✅ 현재 계단(n)에 도달하는 총 가짓수를 반환한다.
        return dp[n]
```
