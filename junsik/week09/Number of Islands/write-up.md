# LeetCode 200. Number of Islands

## 1. 문제

`m x n` 크기의 2차원 문자 배열 `grid`가 주어진다.

* `'1'` : 육지(Land)
* `'0'` : 바다(Water)

상하좌우로 연결된 `'1'`들을 하나의 섬(Island)으로 간주할 때, 전체 섬의 개수를 구하는 문제이다.

---

## 2. 문제 링크

https://leetcode.com/problems/number-of-islands/

## 3. 문제 접근법

Flood Fill 문제와 매우 유사한 그래프 탐색 문제라는 점을 먼저 파악하였다. 차이점은 시작 좌표가 주어지는 것이 아니라, 전체 배열을 순회하면서 새로운 섬을 발견할 때마다 탐색을 시작해야 한다는 것이다.

풀이 과정은 다음과 같다.

1. 배열 전체를 순회한다.
2. 현재 위치가 `'1'`이라면 새로운 섬을 발견한 것이므로 섬의 개수를 1 증가시킨다.
3. DFS를 수행하여 현재 위치와 연결된 모든 육지를 방문 처리한다.
4. 방문한 육지는 `'0'`으로 변경하여 다시 탐색하지 않도록 한다.
5. 모든 칸을 확인한 후 섬의 개수를 반환한다.

DFS에서는 다음과 같은 순서로 탐색을 진행하였다.

* 배열 범위를 벗어나면 종료
* 현재 칸이 `'1'`이 아니면 종료
* 현재 칸을 `'0'`으로 변경하여 방문 처리
* 상, 하, 좌, 우 네 방향을 재귀적으로 탐색

---

## 4. 소스코드

```cpp
class Solution {
public:
    void dfs(vector<vector<char>>& grid, int r, int c) {
        if (r < 0 || r >= grid.size() || c < 0 || c >= grid[0].size())
            return;

        if (grid[r][c] != '1')
            return;

        grid[r][c] = '0';

        dfs(grid, r - 1, c);
        dfs(grid, r + 1, c);
        dfs(grid, r, c - 1);
        dfs(grid, r, c + 1);
    }

    int numIslands(vector<vector<char>>& grid) {
        int count = 0;

        for (int i = 0; i < grid.size(); i++) {
            for (int j = 0; j < grid[0].size(); j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }

        return count;
    }
};
```

## 5. 새로 알게 된 점

* Flood Fill과 DFS의 구조는 거의 동일하지만, 이번 문제는 시작 위치가 정해져 있지 않아 전체 배열을 먼저 탐색해야 한다.
* 방문 배열을 따로 만들지 않고, 방문한 육지를 `'0'`으로 변경하여 방문 여부를 관리할 수 있다.
* 하나의 섬을 발견하면 DFS 한 번으로 연결된 모든 육지를 처리할 수 있으므로 같은 섬을 여러 번 세지 않는다.
* DFS는 단순히 탐색만 하는 것이 아니라, 연결된 요소를 하나의 그룹으로 묶는 데에도 자주 활용된다는 것을 알게 되었다.

---

## 6. 느낀점

Flood Fill을 먼저 풀고 이 문제를 해결하니 전체적인 구조가 거의 같아서 훨씬 쉽게 접근할 수 있었다. 처음에는 Flood Fill 코드를 그대로 가져오면서 불필요한 매개변수를 사용했지만, 문제의 목적에 맞게 DFS를 단순화하니 구현이 깔끔해졌다. DFS의 기본 패턴을 어느 정도 익힌 만큼, 다음에는 섬의 개수를 세는 것이 아니라 넓이를 구하거나 최단거리를 구하는 응용 문제에도 도전해 보고 싶다.
