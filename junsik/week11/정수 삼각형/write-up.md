# 문제

삼각형의 꼭대기에서 시작하여 아래층으로 내려가면서 이동할 때, 지나온 숫자의 합이 최대가 되는 경로의 합을 구하는 문제이다. 한 칸 아래로 이동할 때는 바로 아래 또는 오른쪽 아래로만 이동할 수 있다.

# 문제링크

https://school.programmers.co.kr/learn/courses/30/lessons/43105

# 문제 접근법

DP를 이용하여 각 위치까지 도달했을 때의 최대 합을 저장하였다.

`dp[i][j]`를 **i행 j열까지 도달했을 때의 최대 합**으로 정의하였다.

각 위치는 세 가지 경우로 나누어 계산하였다.

* 맨 왼쪽은 위에서만 내려올 수 있다.
* 맨 오른쪽은 왼쪽 위에서만 내려올 수 있다.
* 가운데는 위와 왼쪽 위 중 더 큰 값을 선택하여 현재 값을 더한다.

모든 위치를 계산한 뒤 마지막 행에는 각 위치까지의 최대 합이 저장되어 있으므로, 마지막 행에서 가장 큰 값을 찾아 반환하였다.

# 전에 풀었던 것과 달라진 점

* 이전에는 DP의 점화식을 이해하는 데 집중했다면, 이번에는 직접 2차원 DP 배열을 구현하였다.
* `dp[i][j]`가 무엇을 의미하는지 명확하게 정의한 뒤 점화식을 적용하였다.
* 맨 왼쪽, 맨 오른쪽, 가운데를 각각 별도로 처리해야 하는 이유를 이해하고 직접 구현하였다.
* 마지막 행에는 모든 가능한 경로의 최대 합이 저장된다는 점을 이해하여 `max_element()`를 이용해 최댓값을 구하도록 구현하였다.
* `vector<vector<int>> dp = triangle;`와 같이 원본과 동일한 크기의 DP 배열을 생성하는 방법을 익혔다.

# 느낀점

처음에는 DP 배열을 어떻게 만들어야 하는지와 경계 조건을 처리하는 부분이 가장 헷갈렸지만, 직접 구현하면서 왜 맨 왼쪽과 맨 오른쪽을 따로 처리해야 하는지 이해할 수 있었다. 또한 DP에서는 현재 위치의 값을 계산하기 전에 이전에 계산한 결과를 그대로 활용한다는 개념이 조금씩 익숙해졌고, 앞으로도 "현재 위치까지의 최적해를 저장한다"는 관점으로 DP 문제를 접근하면 훨씬 수월하게 풀 수 있을 것 같다.
