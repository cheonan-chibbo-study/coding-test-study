# 문제 접근법

파일명을 다음 세 부분으로 분리하였다.

* HEAD : 숫자가 나오기 전까지의 문자열
* NUMBER : 최대 5자리 숫자
* TAIL : 나머지 문자열

HEAD는 대소문자를 구분하지 않고 오름차순 정렬하였다.

HEAD가 같다면 NUMBER를 숫자로 변환하여 오름차순 정렬하였다.

두 조건까지 모두 같다면 기존 입력 순서를 유지해야 하므로 `stable_sort()`를 사용하였다.

# 새로 알게 된 점

* 문자열을 원하는 기준으로 분리하여 사용할 수 있다.
* `stable_sort()`를 사용하면 기존 순서를 유지하면서 정렬할 수 있다.
* `tolower()`, `isdigit()`을 활용한 문자열 처리를 연습할 수 있었다.

# 느낀점

복잡한 알고리즘보다는 문자열을 정확하게 분리하는 구현 능력이 중요한 문제였다. 정렬 기준을 단계별로 나누어 생각하니 해결할 수 있었다.
