# 문제 접근법

먼저 A~Z를 1~26번으로 사전에 저장하였다.

현재 위치에서 시작하여 사전에 존재하는 가장 긴 문자열을 찾고, 해당 번호를 정답에 저장하였다.

이후 찾은 문자열 뒤에 다음 문자를 붙인 새로운 문자열을 사전에 추가하였다.

문자열 끝까지 이 과정을 반복하여 정답을 구하였다.

# 새로 알게 된 점

* map을 이용해 문자열 사전을 구현할 수 있다.
* 문자열을 한 글자씩 탐색하는 것이 아니라 가장 긴 문자열을 찾아야 한다.
* LZW 압축 알고리즘의 기본 원리를 이해할 수 있었다.

# 느낀점

처음에는 어려워 보였지만, 사전을 만들고 가장 긴 문자열을 찾는 과정을 반복하는 구현 문제였다. 문자열 처리와 map 활용 연습에 도움이 된 문제였다.
