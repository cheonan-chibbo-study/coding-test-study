# 문제 접근법

먼저 1부터 순서대로 행렬을 생성하였다.

각 쿼리마다 좌표를 0-based 인덱스로 변환한 후, 테두리를 시계 방향으로 한 칸씩 이동시켰다.

왼쪽 → 아래 → 오른쪽 → 위 순서로 값을 이동시키며, 이동한 값들 중 최솟값을 함께 갱신하였다.

각 쿼리마다 구한 최솟값을 answer에 저장하였다.

# 새로 알게 된 점

* 좌표 문제는 이동 순서를 잘 정하는 것이 중요하다.
* 값을 덮어쓰지 않기 위해 임시 변수(temp)를 활용할 수 있다.
* 문제에서 주어진 좌표가 1부터 시작하는지 항상 확인해야 한다.

# 느낀점

구현 문제이지만 복잡한 알고리즘은 필요하지 않았다. 좌표 이동 순서를 차근차근 나누어 생각하면 해결할 수 있었음.
