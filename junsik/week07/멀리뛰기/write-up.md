# 문제 접근법

`dp[i]`를 **i칸까지 도달하는 방법의 수**라고 정의하였다.

마지막 이동은 1칸 또는 2칸만 가능하므로, `i`칸에 도달하는 경우의 수는 `i-1`칸에서 1칸 이동한 경우와 `i-2`칸에서 2칸 이동한 경우를 더한 값이 된다.

초기값인 `dp[1] = 1`, `dp[2] = 2`를 설정한 뒤, 점화식 `dp[i] = dp[i-1] + dp[i-2]`를 이용하여 반복문으로 값을 계산하였다. 계산 과정에서 오버플로우를 방지하기 위해 매번 `1234567`로 나눈 나머지를 저장하였다.

# 소스코드

```cpp
#include <string>
#include <vector>

using namespace std;

long long solution(int n) {
    if(n == 1)
        return 1;

    vector<int> dp(n + 1);

    dp[1] = 1;
    dp[2] = 2;

    for(int i = 3; i <= n; i++)
    {
        dp[i] = (dp[i - 1] + dp[i - 2]) % 1234567;
    }

    return dp[n];
}
```

# 새로 알게 된 점

* DP(Dynamic Programming)는 **이미 계산한 결과를 저장해 두고 재사용하는 알고리즘 기법**이다.
* DP 문제는 먼저 `dp[i]`가 무엇을 의미하는지 정의한 뒤, 점화식과 초기값을 설정하는 것이 중요하다.
* 이 문제에서는 `dp[i] = dp[i-1] + dp[i-2]`라는 점화식을 이용하여 해결할 수 있었다.
* 큰 수가 발생하는 문제에서는 계산 과정에서 `% 1234567`을 적용하여 오버플로우를 방지할 수 있다.

# 느낀점

이번 문제를 통해 DP를 처음 접하게 되었는데, 처음에는 어렵게 느껴졌지만 `dp[i]`의 의미를 정의하고 점화식을 세우는 과정을 이해하니 구현은 비교적 간단했다. 앞으로 DP 문제를 풀 때도 상태 정의, 점화식, 초기값을 먼저 생각하는 습관을 가져야겠다고 느꼈다.
