# 접근 방법
처음엔 다음과 같은 순서로 접근했습니다.  
 
1. 이동할 수 있는 모든 경로를 본다.
2. 경로는 처음과 끝이 동일한 gate이고, 중간에 다른 gate가 낄 수 없으며 중간에 산봉우리가 포함되어야 한다.
3. 해당 경로에서 intensity 를 구한다.
4. intensity는 이동 경로 중에서 가장 큰 간선 값이다.

하지만 막상 구현을 해보니 생각대로 잘 되지 않았고 애초에 설계에서 제대로 한 건지 확신이 서지 않았습니다.

이미 시간이 30분 정도가 지났고 더 고민해봤자일 것 같아서 AI의 도움을 받았습니다.
