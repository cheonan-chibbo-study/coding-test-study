# 문제 링크
https://leetcode.com/problems/partition-array-into-two-arrays-to-minimize-sum-difference/submissions/1909778273/

# 사고 흐름
## 1. 요구 사항
2*n 길이의 배열이 주어진다.
배열을 두 개의 배열로 나누는데 두 배열은 길이가 n이다.
이때 만들어진 두 배열의 총합의 최소값을 구해라.

## 2. 풀이 방법
1. 각 숫자를 고르거나 고르지 않는 모든 경우를 따진다. O(2^30)
2. 2*N 길이의 배열을 정확히 반 나눈다. -> 나누어진 배열에서 고르거나 고르지 않는 모든 경우를 따지면서, {고른 숫자의 개수: 고른 숫자의 총합 리스트} 형태의 해시맵으로 저장한다. -> 왼쪽 배열에서 0개에서 N개까지 고르는 모든 경우를 따지면서, 그때의 우측 배열의 개수를 구하고, 그때의 합 리스트에 대해서 선택하면 차이가 가장 작은 값이 되는 수를 찾는다.
