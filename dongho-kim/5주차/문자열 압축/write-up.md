# 접근 방법
1. 압축할 길이를 1부터 `len(s) // 2` 까지 기준을 잡습니다.
2. 그리고 `range(0, len(s), size)` 까지 돌면서 `substr`을 조회합니다.
3. 해당 `substr`을 딕셔너리에서 조회합니다. 만약 없다면 Value를 1로 세팅해 저장합니다. 동일한 Key 값이 있다면 Value에 1을 더합니다.  
이때, `substr`이 없다는 뜻은 **연속해서 등장하지 않았음**을 의미합니다. 따라서 이전까지 딕셔너리에 저장해놓은 압축 정보를 리스트에 저장하고, 딕셔너리를 초기화 해줍니다.
4. 끝까지 모두 순회했다면 `size`를 기준으로 한 압축 결과를 문자열로 만들고, 최소 길이를 갱신합니다.

시간 복잡도를 신경써서 접근 방법을 고민하는 건 좋지만, 고민만 하다가 문제를 못푸는 경우가 더 쉽게 발생하는 듯하다.  
이럴 땐 일단 비효율적인 접근 방법이라도 구현해가면서 규칙을 찾는 것도 하나의 방법이 될 수 있겠다.
