# 접근 방법
처음엔 아래 세 가지 방법을 떠올렸습니다. 하지만 문제에서 요구하는 시간 복잡도를 넘는 방법들이었습니다.

1. -10^9부터 10^9 까지 크기의 배열을 만들고, nums 순회하면서 숫자에 해당하는 인덱스에 값을 +1 한다. 그리고 해당 배열을 순회하면서 최장 길이를 측정한다. -> (O(10^18))
2. 최소 힙을 만들고 nums를 순회하면서 힙에 삽입한다. -> O(nlogn)
3. 정렬한다. -> O(nlogn)

그 다음으로 생각한 방법은 "Key랑 Value 모두 정수를 가지는 딕셔너리를 만들고, Key가 Value를 가리키는 의미로 사용"하는 방법입니다. 이는 `nums`를 한번만 순회하면 되기에 O(n) 이긴 합니다.  
그런데 이렇게 딕셔너리를 만들고 나서, 최장 길이를 측정하는 과정에서 O(n) 만큼의 효율적인 방법을 찾지 못했습니다.

결국 시간이 많이 지나 AI의 도움을 받았습니다.  
단순하게 `nums`를 Set으로 만들고, `nums`를 순회하면서 해당 숫자보다 더 작은 값이 없는 값에서부터 시작하여 다음 값이 없을 때까지 집합에서 찾는 방식이었습니다.

# 배운 점
1. 딕셔너리에서 Key 값을 삭제하는 세 가지 방법을 알게 됐다.
2. 존재 여부에 대한 최적화는 Set 임을 떠올려야겠다.
