# 문제 링크
https://www.acmicpc.net/problem/13459

# 사고 흐름
## 1. 요구사항
N x M 크기의 보드가 있고, 빨간 구슬과 파란 구슬이 주어진다.
상하좌우로 보드를 기울여 구슬을 움직인다.
빨간 구슬을 구멍에 10번 이내에 넣으면 1을 반환, 파란 구슬이 먼저 들어가거나 10번 이내에 넣지 못하면 0을 반환한다.

## 2. 접근 방법
기본 틀은 BFS로 구슬들의 위치를 상하좌우 옮긴 모든 경우에 대해서 큐에 삽입한다.  
이떄 구슬이 겹칠 수 있는데, 더 먼거리를 이동한 구슬이 한 칸 뒤로 가는 식으로 위치를 보정한다.

# 배운 점
구현 너무 빡세다 ㅜ
