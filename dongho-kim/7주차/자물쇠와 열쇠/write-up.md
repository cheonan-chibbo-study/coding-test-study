# 사고 흐름
## 1. 요구 사항
자물쇠는 N x N 크기의 격자이고, 열쇠는 M x M 크기의 격자 모양이다.
자물쇠는 홈이 파여있고, 열쇠도 홈과 돌기가 있다.
열쇠는 회전과 이동이 가능하다.
열쇠의 돌기 부분을 자물쇠의 홈 부분에 딱 맞게 채우면 자물쇠가 열린다.

자물쇠 범위에서 벗어난 열쇠는 아무런 영향이 없지만, 자물쇠 영역 내에서 열쇠의 돌기와 열쇠의 돌기가 만나서는 안된다.

자물쇠의 모든 홈을 채워야 열린다.

## 2. 풀이 방법
Key의 (0, 0) 위치를 Lock의 (-M + 1, -M + 1) 부터 (N-1, N-1) 좌표까지 모두 배치하는 모든 경우를 따진다.  
중간에 모든 홈을 채우면 바로 True를 반환한다.  
끝까지 갔는데 못채웠으면 우측으로 90도 회전한다.  
회전을 네 번하면 False를 반환한다.  

시간 복잡도: O((M+N)^2 * M^2)  
M, N 모두 최대 20.  
최대 연산 수: 640,000
