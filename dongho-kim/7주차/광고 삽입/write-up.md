# 사고 흐름
## 1. 요구 사항
동영상 길이가 주어진다.
시청자들이 해당 동영상의 어떤 구간을 재생했는지 알 수 있는 재생구간 기록이 있다.
이 기록을 바탕으로 공익 광고가 삽입될 최적의 위치를 골라야 한다.

## 2. 풀이 방법
1. 동영상 길이를 초 단위로 환산한다. 해당 길이만큼 배열을 만든다.
2. 시청자들의 동영상 재생 구간도 마찬가지로 초 단위로 환산한다. 해당 구간만큼 배열에 기록한다. (imos)
3. imos 한 결과를 누적합해서 구간별 누적 시청자 수를 구한다.
4. 해당 배열을 다시 누적합해서, 광고가 수행되는 구간동안의 총 점수를 O(1)만에 구한다.
5. 그 값이 가장 큰 시작점을 반환한다.
