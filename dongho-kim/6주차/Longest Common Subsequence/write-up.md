# 문제 링크
https://leetcode.com/problems/longest-common-subsequence/

# 접근 방법
1. Brute-Force
가장 분명하게 생각 난 완전 탐색 방식으로는 "길이가 1부터 min(len(text1), len(text2)) 까지의 부분 문자열 길이를 정한다. -> 해당 길이만큼 각 문자에서 부분 문자열을 구한다. -> 두 부분 문자열을 비교한다." 였습니다.  
이는 `itertools.combinations` 덕분에 구현은 쉬웠지만 역시나 시간 초과가 발생했습니다.

어떻게 개선하면 좋을 지 도통 떠오르지가 않아 AI에게 도움을 받았습니다.

2. 바텀업 DP
알고보니 이 문제가 그 유명한 LCS 문제임을 이제야 깨달았습니다..!  
바텀업 DP도 배운 적이 있는데 그때 맨 먼저 풀어봤던 문제였습니다.  

그런데 문득 탑다운으로는 해결할 수는 없을까? 싶어서 AI에게 물어보니 흐름이 완전 똑같은 재귀함수를 작성해주었습니다.

# 배운 점
1. 바텀업은 싫어요..
2. 탑다운으로 접근한다 해도 아이디어를 떠올리기가 너무 어려운 문제였습니다.
