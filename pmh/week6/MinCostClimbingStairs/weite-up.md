# 문제링크
https://leetcode.com/problems/min-cost-climbing-stairs/description/
# 30분내 어디까지 풀었는가
탑다운 + 메모이제이션 으로 풀었지만 코스트 최솟값을 더하는 방식이 틀려 해메다가 초과
# 접근방법
1. 배열 바로 한칸 밖에 꼭대기를 오르는 문제이므로 배열 의 길이를 그대로받는다
2. 배열 다음칸(꼭대기) = 최솟값(dfs(n-1),dfs(n-2)) 로 꼭대기에 한칸으로 올라갈때의 최솟값 두칸으로 올라갈때의 최솟값중 더 작은값을 구한다
```java

   Before     if(memo[i] != 0) return memo[i]; // -> 시간 초과
                
        // cost 가 0 일시 최소비용이 진짜 0이 될수있어서 체크가안되서 메모이제이션이 깨질수있음 -> 방문처리로 변경
   After     if (visited[i]) return memo[i];
```
처음 풀때는  전 방식으로 풀었는데 시간 초과 가 났다 그이유로는 cost 의 최소 비용을 구하는것이다보니 cost 가 0 일시 if 에 걸리지않고  
재귀를 돌게되 시간 초과가 난다  
그래서 메모이제이션이 0 이 아닐때 반환하는것이아니라 이미 최솟값을 계산했다는것을 알리기위해 visited 을써서 해결했다
# 배운점 
-메모이제이션 할때 앞으로 visited 을 쓸수도있다는것을 알게됨
