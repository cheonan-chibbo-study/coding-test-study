# 30분내 어디까지 풀었는가
어제 푼 증가하는 가장긴 부분수열 이랑 비슷하게 될수있는 값을붙여 나가면서 할면 될것같은데 구현이 쉽징않아서 초과
# 접근방법
1. dp[i][j] = text1의 앞에서 i개 , text2 의 앞에서 j 개를 사용했을 때의 LCS 길이
2. 즉 text.charAt(i-1) == text2.charAt(j-1) 이면 둘다 공통 수열에 포함 가능  
   -> dp[i][j] = dp[i-1][j-1] + 1
3. 다르면 둘중 하나를 버려야된다  
    -> dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1])
