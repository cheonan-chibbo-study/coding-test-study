# 문제링크

# 30분내 어디까지 풀었는가
가능한 모든 메뉴 조합 모두 구하고 문제를 잘못 이해해서 그냥 주문횟수 2개 이상인애들만 리스트에 넣다가 시간초과

# 접근방법
- 각 손님마다 주문한 단품메뉴들의 모든 조합을 구한다 
- 조합을 구할때 중복되는 조합이면 갯수를 +1 한다
- 구한 모든 조합과 주문된횟수 에서 요리사가 원하는 코스길이 중 제일 많이 주문된 횟수 을 구한다
- 제일 많이 주문된 횟수와 같은 코스요리길이를 리스트에 넣는ㄴ다
- 정렬후 리스트를 String[] 로 치환해 리턴한다
