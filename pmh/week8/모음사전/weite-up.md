# 문제링크

# 30분내 어디까지 풀었는가
25분내로 풀었으나 bfs 방법이 고치는라 틀려버려서 시간을 초과함

# 접근방법
bfs 탐색을 활용해 모든문자의 조합 을 완성해가면서 카운트를 센다.  
문자를 만들다가 타켓문자와 동일한문자가 생기다면 해당 카운터를 반환한다

# 배운점 
StringBuilder,List 를 써서 bfs 를 구현할때는 원상복구가 필요했는데 그이유가 재귀방식으로 list,stringBUilder 를 넘길때  
같은 객체를 사용하기때문에 이라는것을 알게됬다  
String,래퍼클래스,불변 객체 같은것들은 재귀로 넘기면 새로운 객체를 생성해 넘기므로 원상복구 코드가 필요없다는것을 알게됬다.
