# 30분내 어디까지 풀었는가
그래프를 만들고 다익스트라 알고리즘 까지 구현은 성공했으나 둘이 갈라진다는 글을 못읽어서 그냥 a,b 의 거리 최소값 만 찾으면 되는거아닌가?  
라는 생각에 그냥 거리[a],거리[b]  최소값 비교만 해서 반환해줬다가 틀린후 분기점이 있다는 글을읽고 문제를 다시이해서 풀려고하는데 시간이 초과됨
# 접근방법
1. 두사람이 각 분기점에서 내린후 다시 택시를 타고 각자 목적지로 가는거니깐
2. 출발지 s 에서 시작해 각 분기점의 최소 거리를 구한다 
3. 이제 각 분기점에서 a,b 까지 가는 최소 거리를 구해야한다 
4. 분기점에서 a,b 까지 간다는 소리는 결국 a,b 에서 분기점까지 간다는 소리와 같기때문에 각 a,b 를 출발해 분기점의 최소 거리를 구하는 배열 2개를 구한다
5. 각 3개의 거리 배열 를 구한후 각 노드의 번호에 맞는 거리 배열들을 더하면서 최소값을 찾는다
   ex) 노드 1 이 분기점이라면 S거리배열[1] + a거리배여례[1] + b거리배열[1] 이렇게 노드마다 더해가면서 최소값을 찾는다

1. 처음에 풀때는 whil 반복문 3개로 써서 풀었는데 나중에 최적화할때 메소드를 써 코드를 최적화했다.
