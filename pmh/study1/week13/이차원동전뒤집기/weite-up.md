# 접근방법
1. 모든 행 뒤집기 조합을 시도한다.
2. 그 조합에 따라 0번째 행을 target과 비교한다.
3. 다른 열은 뒤집는다고 가정한다.
4. 전체 board가 target과 같아지는지 검사한다.
5. 가능하면 뒤집은 행 수 + 뒤집은 열 수로 최소값 갱신

## 비트마스크 부분 설명

```java
for (int rowMask = 0; rowMask < (1 << n); rowMask++)
```

`n`개의 행이 있으면, 각 행은 두 가지 상태를 가질 수 있다.

```text
뒤집음 / 안 뒤집음
```

즉, 행이 `n`개라면 전체 경우의 수는 다음과 같다.

```text
2^n
```

예를 들어 `n = 3`이면 행은 총 3개이다.

```text
0번 행
1번 행
2번 행
```

각 행을 뒤집을지 말지를 비트로 표현하면 다음과 같다.

```text
000 → 아무 행도 안 뒤집음
001 → 0번 행 뒤집음
010 → 1번 행 뒤집음
011 → 0번 행, 1번 행 뒤집음
100 → 2번 행 뒤집음
101 → 0번 행, 2번 행 뒤집음
110 → 1번 행, 2번 행 뒤집음
111 → 0번 행, 1번 행, 2번 행 전부 뒤집음
```

따라서 `rowMask`는 행 뒤집기 조합 하나를 의미한다.

---

## i번째 행을 뒤집는지 확인하는 코드

```java
if ((rowMask & (1 << i)) != 0)
```

이 코드는 `rowMask`에서 `i`번째 비트가 켜져 있는지 확인하는 코드이다.

```java
1 << i
```

는 `1`을 왼쪽으로 `i`칸 이동시키는 연산이다.

예를 들어 `i = 0`이면:

```text
1 << 0 = 001
```

`i = 1`이면:

```text
1 << 1 = 010
```

`i = 2`이면:

```text
1 << 2 = 100
```

---

## 예시: rowMask = 5

```java
rowMask = 5
```

`5`를 이진수로 표현하면 다음과 같다.

```text
101
```

이때 각 비트의 의미는 다음과 같다.

```text
2번 비트 1 → 2번 행 뒤집음
1번 비트 0 → 1번 행 안 뒤집음
0번 비트 1 → 0번 행 뒤집음
```

즉,

```text
0번 행 뒤집음
1번 행 안 뒤집음
2번 행 뒤집음
```

이다.

## AND 연산으로 확인하기

예를 들어 `rowMask = 5`일 때:

```text
rowMask = 101
```

### 0번 행 확인

```java
rowMask & (1 << 0)
```

```text
101
& 001
-----
001
```

결과가 `0`이 아니므로 0번 행은 뒤집는다.

### 1번 행 확인

```java
rowMask & (1 << 1)
```

```text
101
& 010
-----
000
```

결과가 `0`이므로 1번 행은 뒤집지 않는다.

### 2번 행 확인

```java
rowMask & (1 << 2)
```

```text
101
& 100
-----
100
```

결과가 `0`이 아니므로 2번 행은 뒤집는다.

---

## 정리

```java
if ((rowMask & (1 << i)) != 0)
```

의 의미는 다음과 같다.

```text
rowMask에서 i번째 비트가 1이면
→ i번째 행을 뒤집는다.

rowMask에서 i번째 비트가 0이면
→ i번째 행을 뒤집지 않는다.
```
