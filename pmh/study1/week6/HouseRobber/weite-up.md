# 접근방법
- 인접한 집을 털지 못하니깐 마지막 집을 터는 경우 n 과 마지막 집 전 집 을 터는 경우 n-1 중 최대값을 구하면 될것같다고 생각했다
- 하지만 그게아닌 n 부터 인접하지 않게 n-2 이씩 해서 터는 경우를 구하고 n-1 씩해서 털지 않은집을 구한후 두개 중 더 큰값을 구하는 문제였다
