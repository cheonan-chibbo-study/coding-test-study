# 문제링크
https://leetcode.com/problems/climbing-stairs/
# 30분내 어디까지 풀었는가
재구 + 메모이제이션 방법으로 풀려고했으나 n 일때 n-1 +n-2 방법을 못떠올려서 시간초과
# 접근방법
1. 계단을 한번에 1계단 또느 2계단 오를수있으니 계단 n 을 올라야하면 계단 n 을 오르는 경우의수는 n 에 오르기전에 1계단 오르는 n-1 과 오르기전 2계단 오르는 n-2 경우의수가있다
2. 그러니 memo[n] = dfs(n-1) + dfs(n-2) 으로 직전에 1칸 오르는 경우의수 와 2칸 오르는 경우의 수를 더하고 메모이제에션에 추가한다
3. 메모 가 0 이 아니라면 이미 최소경의수를 구한거니 갱신하지않고 바로 반환
# 배운점 
탑다운 + 메모이제이션 으로 디피 푸는 방법을 어렴풋이 배운것같다
