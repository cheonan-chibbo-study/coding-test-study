# 문제링크
https://leetcode.com/problems/longest-consecutive-sequence/
# 30분내 어디까지 풀었는가
1. 다풀고 제출까지 완료했다
# 접근방법
1. 정렬 되지 않은 배열이 들어오고 연속되는 가장 긴 부분순열을 구해야되니 일단 배열을 정렬 해야겠다고 생각했다
2. 그후 배열 0 부터 탐색하면서 배열[1] == 배열[0]+1 이라면 즉 연속된 수라면 길이를 +1 카운트하고 해당길이가 max보다 크면 max에 저장한다
3. 만약 연속된 배열이 끓겼다면 길이를 1 로 초기화한다.
4. 그러나 나는 sort 정렬를 써서 풀었는데 문제의 조건에는 O[n] 에 실행되어야한다고 되어있다 sort를 쓰면 O[n log n] 이되서 문제에 맞지는 않지만 제출하면 정답으로 제출된다
5. 그래서 개선점으로 Set 을써서 사용했다 set 에 nums 의 수들을 넣는다
6. set에서 숫자를 하나씩뽑아와 num에 담고 contains 를 사용해 num-1 나보다 작은 연속된 수가 없다면 이 수를 시작점으로삼고 길이를 1 로선언한다
7. 그후 반목문을 num+1 로 연속된수를 찾고 있다면 길이 와 num 를 +1 하고 길이를 max 값에 넣는다 
# 배운점 
 1. sort 정렬이 O(n lon n) 인걸 알게되었다.
