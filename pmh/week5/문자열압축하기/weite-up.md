# 30분내 어디까지 풀었는가
문자열을 자르고 자른 문자열로 문자열을 증가하면서 자르면서 맞는지 확인후 카운트하는식으로 풀어야겠다고 생각까지는했다  
그러나 문자열을 어떤 식으로 잘라야할지를 떠올리지를 못하고 뇌정지가와서 20분동안 해메이다가 시간초과가 됬다
# 접근방법
1. 문자열 을 자르고 저장
2. 잘린 문자열 다음 부터시작해 갯수에 맞게 문자열을 잘라와서 잘라논 문자열과 같은지 비교하고 같으면 count++
3. 그러다 같은 문자열이 안나오면 스틀링 빌더를 통해 카운터와 해당 문자열을 저장하고 나온 다른 문자를 다시 저장해 다시 반복한다
4. 마지막에 카운트만 하던거 문자열을 처리해주고 끝에 남은 꼬리 문자열들을 처리한다
5. 그후 Math.min 을써서 스트링빌더 길이 를 비교해 최솟값을 넣는다
# 배운점 
- 문제가 쉽지는 않은것같다 막상 풀어보면 이해하기는 어렵지않은데 처음부터 풀려니깐 쉽지가않았다.
