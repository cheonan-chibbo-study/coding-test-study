# 30분내 어디까지 풀었는가
입력받는거에 시간 좀 많이쓴후 최초 출발지에서 가장 가까운 거리로 승객에게 가는 함수 구현하다 시간초과
# 접근방법
1. 택시 처음위치에서 BFS 를 써서 가장 가까운 위치 고객까지 가기
2. 처음위치 -> 가장 가까운 고객 거리까지 연료 계산
3. 가장 가까운 위치 고객 좌표에서 목표지 까지 가장 가까운 거리로 갈수있도록 BFS 로 탐색한다
4. 고객을 태운위치 -> 목표 위치 까지 연료계산
5. 연료가 부족하지 않다면 다음가까운 고객을 태우러간다.
