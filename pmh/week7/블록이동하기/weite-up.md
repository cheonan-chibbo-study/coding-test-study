# 30분내 어디까지 풀었는가
푸는 방법이랑 코드가 살짝 기억나서 코드작성은 금방되는데  
문제가 워낙 조건문이나 반복문 처리할게많고 코드가 길어지니 치는데만 30분이 넘어가서 못풀었다.
# 접근방법
1. 로봇의 상태를 정의하고 (11 12) ,(12 11) 이렇게 같은위치이지만 좌표가 다르게 나타날때를 대비해 항상 로봇의 좌표는 정렬해서 저장한다
2. 상화자우, 회전을 하면 BFS 탐색을 한다
# 배운점 
지금 문제는 이동거리가 똑같이 1 씩 늘어나니 큐의 선입선출만으로도 촤단거리가 측정가능하다  
그러나 만약 비용이 다르다면 최단 거리를 구하기위해서 비용 최소 순으로 정렬해서 출력되는 우선순위큐를 사용해야한다
