# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. map 을 이용해 참가자 를 참가자 , 참가자수 를 키, 값 으로해 저장한다.
2. 그렇게 저장한 map 을 이용해 완주 한 사람의 이름을 통해 참가자수 -1 을 한다.
3. 참가자가 경기를 완주했다면 참가자수가 0 일 될것이다 또한 동명이인이라도 둘다 완주했다면 참가자수가 0 이고 완주를 못했다면 0 이 아니기때문에  
   0 이아닌 사람이 경기를 완주하지 못한 사람이 된다.
# 시간/공간 복잡도

시간 복잡도: **O(N)**
- `participant`를 순회하며 HashMap에 저장: **O(N)**
- `completion`을 순회하며 개수 감소: **O(N-1) ≈ O(N)**
- HashMap을 순회하며 값이 0이 아닌 선수를 찾음: **O(N)**

따라서 전체 시간 복잡도는 **O(N)** 입니다.

공간 복잡도: **O(N)**
- 참가자 이름과 개수를 저장하는 HashMap을 사용하므로 최악의 경우 참가자 수만큼 저장되어 **O(N)** 입니다.
