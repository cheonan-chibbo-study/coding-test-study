# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.
구현코드는 생각나는데 문법이 생각 나지 않았다.

# 접근방법
1. 재귀방식을 통해 각 주문에서 가능한 메뉴 조합을 모두 만든다.
2. map 를 통해 중복된 조합의 갯수를 센다
3. 코스 길이 와 같은 메뉴 조합 중 가장 많이 주문된 애들을 고른다
# 시간/공간 복잡도
시간 복잡도: O(n × 2^m × m)
- n: 주문 개수
- m: 한 주문의 최대 메뉴 개수
- 각 주문에서 가능한 모든 조합(2^m)을 생성하고 문자열을 HashMap에 저장

공간 복잡도: O(n × 2^m)
- 생성된 메뉴 조합을 HashMap에 저장
- DFS 재귀 호출은 O(m)
