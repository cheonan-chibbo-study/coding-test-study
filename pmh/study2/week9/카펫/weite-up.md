# 30분내 어디까지 풀었는가
30분내 풀이완료
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.

# 접근방법

- `yellow`의 약수를 모두 탐색하여 내부 직사각형의 가로, 세로 크기를 구한다.
- 내부 크기가 `row × col`이라면 테두리 갈색이 한 칸씩 둘러싸므로 전체 크기는 `(row + 2) × (col + 2)`가 된다.
- 전체 넓이에서 `yellow`를 빼면 갈색 칸의 개수를 구할 수 있다.
    - `brown = (row + 2) × (col + 2) - yellow`
- 계산한 갈색 칸 수가 입력으로 주어진 `brown`과 같다면 `{전체 가로, 전체 세로}`를 반환한다.
- 약수는 `√yellow`까지만 탐색하면 모든 경우를 확인할 수 있다.

# 시간/공간 복잡도

- **시간 복잡도:** `O(√yellow)`
    - `yellow`의 약수를 찾기 위해 `1`부터 `√yellow`까지만 탐색한다.
- **공간 복잡도:** `O(1)`
    - 별도의 자료구조를 사용하지 않고 상수 개의 변수만 사용한다.

# 배운점

- 직사각형의 약수를 이용하면 가능한 모든 가로·세로 조합을 효율적으로 탐색할 수 있다.
- 약수 탐색은 `√N`까지만 확인해도 모든 경우를 찾을 수 있다는 점을 다시 확인했다.
- 테두리 문제는 **전체 넓이 - 내부 넓이 = 테두리 넓이**라는 식으로 접근하면 구현이 간단해진다.
