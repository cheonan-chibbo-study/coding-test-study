# 접근방법

dp(i, j)를 text1의 i번째 문자부터, text2의 j번째 문자부터 시작했을 때 만들 수 있는 LCS의 길이라고 정의한다.

- 현재 두 문자가 같다면 해당 문자를 공통 부분수열에 포함할 수 있으므로
  `1 + dfs(i+1, j+1)`을 선택한다.
- 현재 두 문자가 다르다면 둘 중 하나의 문자를 제외해야 하므로
  `dfs(i+1, j)`와 `dfs(i, j+1)` 중 큰 값을 선택한다.

동일한 (i, j)를 여러 번 계산하므로 메모이제이션을 사용하여 중복 계산을 제거한다.

# 시간/공간 복잡도

시간 복잡도: O(m × n)

공간 복잡도: O(m × n)
