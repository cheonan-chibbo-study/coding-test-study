# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. 연결리스트를 사용해 그래프를 만들고 그래프를 트리로 연결시킨다.
2. 1~n 까지 하나씩 연결된 그래프를 끓는다
   - 연결리스트를 끓을때는 단순히 remove사용시 인덱스 를 삭제하므로 인티제 객체로 변환해 삭제한다
3. 연결이 끟긴 그래프를 재귀방식을통해 탐색한다.
4. 끓긴 그래프 갯수의 차이를 기록한다.
5. 최소 차이를 반환한다.
# 시간/공간 복잡도
시간 복잡도: O(n²)
- 간선(n-1개)을 하나씩 제거하며 반복 → O(n)
- 매번 DFS로 모든 노드와 간선을 탐색 → O(n)
- 따라서 O(n) × O(n) = O(n²)

공간 복잡도: O(n)
- 인접 리스트: O(n)
- visited 배열: O(n)
- DFS 재귀 호출 스택: 최악 O(n)

⇒ 전체 공간 복잡도는 O(n)
