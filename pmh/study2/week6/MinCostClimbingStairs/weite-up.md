# 접근방법

1. `dfs(idx)`를 **idx번째 계단에서 꼭대기까지 도달하는 최소 비용**이라고 정의했다.
2. 현재 계단을 밟으면 `cost[idx]` 비용을 지불해야 한다.
3. 한 번에 1칸 또는 2칸 이동할 수 있으므로 다음 상태는 `idx + 1`, `idx + 2` 두 가지이다.
4. 따라서 현재 위치에서의 최소 비용은 다음 점화식으로 구할 수 있다.

```java
memo[idx] = cost[idx] + Math.min(dfs(idx + 1), dfs(idx + 2));
```

5. 동일한 계단에 여러 번 도달할 수 있으므로 메모이제이션을 사용하여 이미 계산한 결과를 재사용했다.
6. 시작 위치는 0번 계단 또는 1번 계단이므로 두 경우 중 최소값을 반환한다.

```java
return Math.min(dfs(cost, 0), dfs(cost, 1));
```

# 시간/공간 복잡도

시간 복잡도: `O(N)`

공간 복잡도: `O(N)`

- 각 계단의 최소 비용을 memo 배열에 한 번만 저장한다.
- 재귀 호출 스택도 최악의 경우 `O(N)` 사용된다.

# 배운점

- 완전탐색으로 접근하면 동일한 상태를 반복 계산하여 시간 복잡도가 `O(2^N)`까지 증가한다.
- DP 문제는 먼저 "현재 상태를 무엇으로 정의할 것인가?"를 정하는 것이 중요하다.
- 메모이제이션을 적용하면 각 상태를 한 번만 계산하므로 `O(N)`으로 최적화할 수 있다.
- 재귀 DP에서는 배열 접근 전에 기저 조건을 먼저 검사해야 `ArrayIndexOutOfBoundsException`을 방지할 수 있다.
