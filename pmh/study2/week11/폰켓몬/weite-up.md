# 접근방법
1. map 을 사용해서 nums 의 중복을 없애고 총 종류를 구한다.
2. map.size() 가 종류의 갯수가 되므로 nums/2 보다 map.size() 가 크면 num/2 보다 종류가 많다는 소리니 가장 많은 종류를 선택하는것은 nums/2 를 선택하는것이다
3. map 사이즈가 nums/2 보다작으면 종류가 nums/2 보다 종류가 작다는 말이고 가장 많이 종류를 선택하는것은 map.size() 만큼 선택하는것이다

# 시간/공간 복잡도

- **시간 복잡도:** `O(n)`
    - 모든 포켓몬을 한 번 순회하며 `HashMap`에 저장한다.
    - `HashMap`의 삽입/조회는 평균 `O(1)`이다.

- **공간 복잡도:** `O(n)`
    - 최악의 경우 모든 포켓몬이 서로 다른 종류라면 `HashMap`에 `n`개의 종류가 저장된다.
