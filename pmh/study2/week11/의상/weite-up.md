# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. 서로 다른옷을입는 조합의 갯수를 구하는거니 map 을 이용해 옷의 종류의 갯수를 센다
2. 옷을 안입는 경우가 있으므로 각 종류 갯수 + 1 을하고 곱한다.
3. 총 조합갯수중 모든옷을 안입는경우가있으므로 -1 을 뺴고 반환한다
# 시간/공간 복잡도
시간 복잡도:  O(N + K) (N: 옷의 개수, K: 옷 종류의 개수)
공간 복잡도: O(K) (종류별 개수를 저장하는 HashMap)
