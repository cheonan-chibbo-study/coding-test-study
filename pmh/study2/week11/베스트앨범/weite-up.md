# 접근방법
1. Map total 을 이용해 장르마다의 최대 플레이됫 횟수를 구한다.
2. Song 이라는 클래스를 선언해 곡의 번호와 재생횟수를 따로 저장할수있도록한다
3. Map play 를 이애용해 장르 곡번호 재생횟수 가 저장되도록 한다.
4. total 의 키만을 List<String> order 로 받아 장르마다 총 플레이횟수가 많은 순으로 정렬한다
5. 정렬된 장르가 있는 order 을 반복문으로 순회하면서 play 에 있는 음악들중 장르내에서 많이 플레이된 곡 그다음 번호가 낮은곡을 ans에 기록한다.
# 시간/공간 복잡도

시간 복잡도: O(N log N)

- 장르별 총 재생 수 계산: O(N)
- 장르 정렬: O(G log G)
- 각 장르의 노래 정렬: O(N log N)
- 정답 배열 생성: O(N)

(G는 장르의 개수이며 G ≤ N이므로 최종 시간 복잡도는 O(N log N)이다.)

공간 복잡도: O(N)

- 장르별 노래를 저장하는 Map과 정답 리스트 및 배열을 사용하므로 O(N)의 추가 공간이 필요하다.
