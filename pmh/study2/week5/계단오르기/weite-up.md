# 접근방법

계단 n개를 오르는 방법의 수를 구하는 문제이다.

n번째 계단에 도달하는 경우의 수는 마지막에 1칸 올라온 경우와 2칸 올라온 경우로 나눌 수 있다.

따라서 점화식은 다음과 같다.

f(n) = f(n - 1) + f(n - 2)

재귀를 사용하면 동일한 값을 여러 번 계산하게 되므로, 메모이제이션(DP)을 사용하여 이미 계산한 결과를 저장하고 재사용하였다.

기저 조건은 다음과 같이 설정하였다.

- f(0) = 1
- f(1) = 1

이후 dfs(n - 1) + dfs(n - 2)를 계산하여 memo 배열에 저장하고 반환하였다.

# 시간/공간 복잡도

시간 복잡도: O(n)

- 각 n에 대해 한 번만 계산하므로 O(n)

공간 복잡도: O(n)

- memo 배열 O(n)
- 재귀 호출 스택 최대 O(n)

# 배운점

- 계단 오르기 문제는 대표적인 피보나치 수열 응용 문제이다.
- 단순 DFS는 동일한 상태를 반복 계산하여 O(2ⁿ)의 시간 복잡도를 가진다.
- 메모이제이션을 적용하면 이미 계산한 값을 재사용하여 O(n)으로 최적화할 수 있다.
- DP 문제에서는 "현재 상태를 어떻게 정의할 것인가"를 먼저 생각하는 것이 중요하다.
- Top-Down(재귀 + 메모이제이션) 방식과 Bottom-Up(반복문) 방식 모두 같은 점화식을 사용한다.
