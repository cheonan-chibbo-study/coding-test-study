# 접근방법

`dp[r][c]`를 **(r, c)를 오른쪽 아래 꼭짓점으로 하는 가장 큰 정사각형의 한 변의 길이**로 정의합니다.

현재 칸이 `'0'`이라면 정사각형을 만들 수 없으므로 `dp[r][c] = 0`입니다.

현재 칸이 `'1'`이라면 정사각형을 확장하기 위해 **위, 왼쪽, 왼쪽 위 대각선**의 정보를 이용합니다.

- 위: `dp[r-1][c]`
- 왼쪽: `dp[r][c-1]`
- 대각선: `dp[r-1][c-1]`

현재 위치에서 한 변의 길이가 `k`인 정사각형을 만들기 위해서는 세 방향 모두 최소 `k-1` 크기의 정사각형을 가지고 있어야 합니다. 따라서 셋 중 가장 작은 값만큼만 확장할 수 있으므로 다음과 같은 점화식을 사용합니다.

```text
if matrix[r][c] == '0'
    dp[r][c] = 0
else if r == 0 || c == 0
    dp[r][c] = 1
else
    dp[r][c] = min(
        dp[r-1][c],
        dp[r][c-1],
        dp[r-1][c-1]
    ) + 1
```

DP를 채워가면서 가장 큰 한 변의 길이를 `maxSide`에 저장하고, 문제에서 요구하는 값은 **정사각형의 넓이**이므로 마지막에 `maxSide * maxSide`를 반환합니다.

# 시간/공간 복잡도

시간 복잡도: **O(m × n)**
- 모든 칸을 한 번씩만 방문합니다.

공간 복잡도: **O(m × n)**
- DP 배열을 사용하여 각 위치에서 끝나는 최대 정사각형의 한 변의 길이를 저장합니다.
