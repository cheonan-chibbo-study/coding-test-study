# 접근방법
1. finish -> start 로 가는 걸로 계산을 시작한다.
2. 재귀방식을통해 finish 에서 왼쪽으로 가능경우 위로가능 경우를 구해 start에 도달 할시 1을 반환한다.
3. 재귀를 통해 구하면서 구한 값들을 메로이제이션 방식을통해 또계산하지않도록 이미 계산값들을 저장한다.
4. 최종적으로 dfs(m-1,n-1) 을 반환한다.
# 시간/공간 복잡도

시간 복잡도: **O(m × n)**
- 각 칸 `(r, c)`은 메모이제이션 덕분에 최대 한 번만 계산됩니다.
- 각 상태에서 수행하는 연산은 상수 시간이므로 전체 시간 복잡도는 `O(m × n)`입니다.

공간 복잡도: **O(m × n)**
- `memo` 배열에 `m × n`개의 값을 저장합니다.
- 재귀 호출 스택은 최악의 경우 `O(m + n)`이 추가로 필요합니다.
- 따라서 전체 공간 복잡도는 `O(m × n)`입니다.
