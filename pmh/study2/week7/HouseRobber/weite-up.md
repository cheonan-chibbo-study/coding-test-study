# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법

`dfs(i)`를 **0 ~ i번째 집까지 고려했을 때 얻을 수 있는 최대 금액**으로 정의했습니다.

각 집에서는 두 가지 선택만 존재합니다.

1. **현재 집(i)을 털지 않는 경우**
    - 이전 집까지의 최적해를 그대로 사용하므로 `dfs(i-1)`

2. **현재 집(i)을 터는 경우**
    - 인접한 집은 털 수 없으므로 `dfs(i-2) + nums[i]`

위 두 경우 중 더 큰 값을 선택하며, 이미 계산한 결과는 메모이제이션을 통해 재사용하여 중복 계산을 제거했습니다.

점화식은 다음과 같습니다.

```java
dfs(i) = Math.max(
    dfs(i - 1),
    dfs(i - 2) + nums[i]
);
```

# 시간/공간 복잡도

시간 복잡도: **O(n)**

공간 복잡도: **O(n)** (메모이제이션 배열 + 재귀 호출 스택)

# 배운점

- DP에서는 **상태(State)의 정의가 가장 중요**하다는 것을 다시 느꼈습니다.
- 처음에는 "마지막 집을 털지, 마지막 전 집을 털지"로 생각했지만, `dfs(i)`를 **0 ~ i번째 집까지의 최적해**로 정의하면 점화식을 훨씬 자연스럽게 세울 수 있었습니다.
- 현재 집을 털면 이전 집은 반드시 제외되어야 하므로 `dfs(i-2) + nums[i]`, 현재 집을 털지 않으면 `dfs(i-1)`이 된다는 점을 이해했습니다.
- 메모이제이션을 적용하면 동일한 부분 문제를 한 번만 계산하여 시간 복잡도를 지수 시간에서 선형 시간으로 줄일 수 있었습니다.
