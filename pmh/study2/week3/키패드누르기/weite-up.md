# 30분내 어디까지 풀었는가
30분내 풀기 실패
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.
2,5,8,0 의 거리를 계산하는 코드를 고민하다 시간초과

# 접근방법
1. 스트링 빌더를 사용해 1, 4, 7 이면 L 을 3, 6, 9 면 R 을 추가한다.
2. \# , \* 및 2,5,8 0 의 경우
```java
1 -> 1
2 -> 2
...
9 -> 9
* -> 10
0 -> 11
# -> 12
* , # , 0 숫자를 부여한후
        
if(num == 0) num = 11; 
를 통해 예외처리하고
        
row = (num - 1) / 3;
col = (num - 1) % 3;
를 사용해 각 숫자를 그대로쓰는게아닌 좌표값으로 사용한다

예)
5 -> 4/3 = 1
     4%3 = 1
이 되 [1,1] 좌표를구할수있다

```
3. 이 식을 통해 왼쪽, 오른쪽 엄지의 거리를 구하고 길이가 더 짧은 엄지를 사용한다 같을시 주사용 엄지를  사용한다.
# 시간/공간 복잡도
시간 복잡도: O(N)  
공간 복잡도:O(N)

# 배운점 
보드판의 인덱스를 나누면 열과 ,행 를 구할수는 있다고는 알고있었는데 제대로된 공식이 떠오르지 쓰지못했다.  
기억 해놔야겠다고 생각했다.  
또한 이문제는 키패드는 항상 고정이기때문에 사전에 좌표를 지정한채 푸는 방법도 가능한다.
```java
row = index / 열의개수;
col = index % 열의개수;

row = (1차원으로 나열했을 때의 위치 번호) / 열의개수;
col = (1차원으로 나열했을 때의 위치 번호) % 열의개수;
```
