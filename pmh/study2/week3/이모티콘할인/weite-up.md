# 30분내 어디까지 풀었는가
30분내 풀지 못함
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.
구할수있는 모든 할인율 조합을 구해야해서 dfs() 로 해야겠다고 떠올리긴했는데  
구현을 고민하다가 시간초과

# 접근방법

1. 각 이모티콘은 10%, 20%, 30%, 40% 중 하나의 할인율을 가질 수 있다.
2. DFS(백트래킹)를 이용하여 모든 할인율 조합(4^M)을 탐색한다.
3. 할인율 조합이 완성되면 각 사용자의 구매 금액을 계산한다.
    - 사용자가 원하는 최소 할인율 이상인 이모티콘만 구매
    - 구매 금액이 기준 금액 이상이면 플러스 가입
    - 아니면 해당 금액을 매출에 반영
4. 모든 사용자를 계산한 뒤
    - 플러스 가입자 수가 더 많으면 갱신
    - 가입자 수가 같으면 매출액이 더 큰 경우 갱신

# 시간/공간 복잡도

시간 복잡도: O(4^M × N × M)

- M: 이모티콘 개수 (최대 7)
- N: 사용자 수 (최대 100)

최대:

4^7 × 100 × 7 ≈ 11,000,000

공간 복잡도: O(M)

- 할인율을 저장하는 `discounts` 배열 사용
- DFS 재귀 깊이 최대 M

# 배운점 
- dfs 를 통해 가능한 수 모드를 탐색하는거는 알고있었는데 기억해내지 못했다 다시한번 상기하게되었다.
