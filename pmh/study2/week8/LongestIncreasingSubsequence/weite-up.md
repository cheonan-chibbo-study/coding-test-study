# 접근방법

`dp[i]`를 **i번째 원소를 마지막으로 하는 가장 긴 증가 부분 수열(LIS)의 길이**라고 정의합니다.

모든 원소는 자기 자신만 선택해도 길이가 1인 증가 부분 수열을 만들 수 있으므로 `dp[i] = 1`로 초기화합니다.

이후 각 원소 `i`에 대해 앞에 있는 모든 원소 `j(0 ≤ j < i)`를 확인합니다. 만약 `nums[j] < nums[i]`라면 `nums[i]`를 `j`에서 끝나는 증가 부분 수열 뒤에 이어 붙일 수 있으므로 다음과 같이 갱신합니다.

```java
dp[i] = Math.max(dp[i], dp[j] + 1);
```

모든 원소에 대해 이를 반복한 뒤, `dp` 배열의 최댓값이 가장 긴 증가 부분 수열의 길이가 됩니다.

# 시간/공간 복잡도

시간 복잡도: **O(n²)**
- 각 원소마다 이전의 모든 원소를 확인합니다.

공간 복잡도: **O(n)**
- `dp` 배열을 사용합니다.
