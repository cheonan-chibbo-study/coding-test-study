# 접근방법

`dfs(i, j)`를 **text1의 i번째부터, text2의 j번째부터 만들 수 있는 가장 긴 공통 부분 수열(LCS)의 길이**라고 정의했습니다.

- **종료 조건**
    - 두 문자열 중 하나라도 끝까지 탐색한 경우 더 이상 공통 부분 수열을 만들 수 없으므로 `0`을 반환합니다.
- **현재 문자가 같은 경우**
    - 현재 문자를 공통 부분 수열에 포함시키고 두 문자열 모두 다음 문자로 이동합니다.
    - `1 + dfs(i + 1, j + 1)`
- **현재 문자가 다른 경우**
    - `text1`의 현재 문자를 건너뛰는 경우와 `text2`의 현재 문자를 건너뛰는 경우 중 더 긴 공통 부분 수열을 선택합니다.
    - `max(dfs(i + 1, j), dfs(i, j + 1))`

동일한 `(i, j)` 상태가 여러 번 호출되므로 메모이제이션을 사용하여 중복 계산을 제거했습니다.

# 시간/공간 복잡도

시간 복잡도: **O(m × n)**
- `m = text1.length()`
- `n = text2.length()`
- `(i, j)` 상태를 최대 한 번씩만 계산합니다.

공간 복잡도: **O(m × n)**
- 메모이제이션 배열 `memo[m][n]`을 사용합니다.
- 재귀 호출 스택은 최대 `O(m + n)`이지만, 전체 공간 복잡도는 `memo`가 지배하므로 `O(m × n)`입니다.
