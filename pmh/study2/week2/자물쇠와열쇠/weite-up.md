# 30분내 어디까지 풀었는가
30분은 넘었지만 풀기완료
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. 자물쇠를 3배 크기로 확장한 배열 중앙에 배치
2. 키를 4방향으로 회전하면서, 모든 위치(n×2 범위)에 올려놓아 자물쇠 홈이 정확히 채워지는지 확인
3. 키+자물쇠의 값이 정확히 1인지 검사 (0=빈곳, 1=채워짐, 2=겹침)



# 시간/공간 복잡도
시간 복잡도: O(n² × m²) — 4번 회전 × (2n)² 위치 × n² 검사 = O(n³) but key 크기 m을 고려하면 O(n² × m²)  
공간 복잡도: O(n²) — 확장 배열 (3n × 3n)
