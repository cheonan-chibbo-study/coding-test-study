# 접근방법
1. 타겟의 값의 인덱스를 물어보는 문제로 이진 검색을 사용해 푼다
2. 이진 검색은 배열 의 중간 값을 기준으로  타겟 값이 중간 값보다 크다면 중간 값의 오른쪽을 탐색하고 작다면 왼쪽을 탐색하는방법으로
3. 이 방식을 반복해 원하는값을 찾는 방법이다
# 시간/공간 복잡도
시간복잡도:

O(logn)

공간복잡도:

O(1)
