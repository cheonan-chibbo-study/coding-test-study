# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. 가능한 모든 부분 조합을 구하는것이라 dfs() 사용해야겠다고 생각했다
2. 중복이 되면 안되니 visited() 을 써서 했지만 visited() 은 [1,2] [2,1] 순서가 달라도 다른 경우로 취급되니 즉 순열 구조이므로 지금 subsets 에 맞지않았다
3. 조합을 만들기위해 i + 1 방식으로 해 탐색할때마다 result 에 cur 값을 넣어 모든 부분조합을 구하도록 했다
    ```java
   dfs(result,cur,i+1,nums);
    ```
```markdown
[]
├── [1]
│   ├── [1,2]
│   │   └── [1,2,3]
│   └── [1,3]
├── [2]
│   └── [2,3]
└── [3]
```
## 시간복잡도
visited 방식

전체를 계속 탐색:

O(n!)

(순열)

i+1 방식

조합 개수만 탐색:

O(2^n)

(subsets)

# 배운점 
visited , i+1 방식과 시간복잡도의 차이를 알게됨
