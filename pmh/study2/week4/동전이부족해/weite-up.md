# 접근방법

처음에는 모든 동전 조합을 만들어서 각 동전의 사용 횟수를 세려고 생각했지만, 경우의 수가 너무 많아 불가능하다.

문제에서 구해야 하는 값은 **"가장 많이 사용된 동전의 개수"의 최솟값**이다.

이를 K라고 하면,

- 각 동전을 최대 K개 이하 사용하여 M원을 만들 수 있는가?
- 만들 수 있다면 K보다 큰 값도 항상 가능하다.
- 만들 수 없다면 K보다 작은 값도 항상 불가능하다.

즉, K에 대해 **단조성**이 존재하므로 이분 탐색을 사용할 수 있다.

이분 탐색의 판별 함수는 다음과 같다.

- 각 동전을 최대 K개까지 사용할 수 있다고 가정한다.
- M원을 만들 수 있는지 DP로 판별한다.
- 만들 수 있으면 더 작은 K를 탐색한다.
- 만들 수 없으면 더 큰 K를 탐색한다.

DP는 Bounded Subset Sum(개수 제한 배낭) 기법을 사용한다.

`dp[i]`를

> 금액 i를 만들 때 현재 동전을 앞으로 몇 개 더 사용할 수 있는지

라고 정의한다.

이를 이용하면 동전 하나당 O(M)에 처리할 수 있어 전체 판별을 O(NM)에 수행할 수 있다.

---

# 시간/공간 복잡도

시간 복잡도:

- 판별 함수: O(NM)
- 이분 탐색: O(log M)

따라서

```text
O(NM log M)
```

최대

```text
300 × 30000 × log₂(30000)
≈ 1.35 × 10^8
```

공간 복잡도:

```text
O(M)
```

DP 배열 하나만 사용하므로

```text
O(30000)
```
