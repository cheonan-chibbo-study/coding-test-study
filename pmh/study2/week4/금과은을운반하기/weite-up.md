# 접근방법

이 문제는 **"주어진 시간 안에 금과 은을 모두 옮길 수 있는가?"** 를 판단할 수 있기 때문에 **이분 탐색(Parametric Search)** 으로 해결할 수 있다.

## 1. 이분 탐색을 사용할 수 있는 이유

시간이 증가할수록 옮길 수 있는 광물의 양은 절대 감소하지 않는다.

예를 들어,

- 10시간 안에 운반 가능
- 20시간 안에 운반 가능
- 30시간 안에 운반 가능

이라면,

- 9시간 → 불가능
- 10시간 → 가능
- 11시간 → 가능
- 12시간 → 가능

처럼 특정 시간을 기준으로

```
불가능 → 가능
```

형태가 나타난다.

따라서 **최소 가능 시간**을 찾기 위해 이분 탐색을 사용할 수 있다.

---

## 2. 특정 시간 T가 주어졌을 때

각 도시가 T 시간 동안 몇 번 운반할 수 있는지 계산한다.

### 왕복 횟수

트럭 1회 왕복 시간

```
2 × t[i]
```

따라서

```
T / (2 × t[i])
```

만큼 완전한 왕복이 가능하다.

---

### 마지막 편도 이동

새 도시로만 이동해도 광물을 전달할 수 있으므로

```
T % (2 × t[i]) >= t[i]
```

이면 마지막 편도 1회를 추가로 수행할 수 있다.

예시

```
t = 3
T = 10

왕복 시간 = 6

10 / 6 = 1회 왕복
10 % 6 = 4

4 >= 3 이므로
편도 1회 추가 가능

총 2번 운반
```

---

## 3. 해당 도시가 옮길 수 있는 최대 광물

운반 횟수를 `cnt`라고 하면

```
cnt × w[i]
```

만큼 운반 가능하다.

하지만 실제 보유한 광물보다 많이 옮길 수는 없으므로

```java
move = Math.min(cnt * w[i], (long) g[i] + s[i]);
```

로 계산한다.

---

## 4. 금, 은, 전체 광물 계산

### 금

최대 `move`만큼 옮길 수 있지만 실제 금은 `g[i]`개만 존재한다.

```java
gold += Math.min(move, (long) g[i]);
```

### 은

```java
silver += Math.min(move, (long) s[i]);
```

### 전체 광물

```java
total += move;
```

---

## 5. 왜 total 검사가 필요한가?

금과 은을 각각 계산하면 실제로 불가능한 경우를 가능하다고 판단할 수 있다.

예시

```
금 70
은 70

운반 가능량 100
```

이라고 하자.

그러면

```
gold = 70
silver = 70
```

이 되어

```java
gold >= a
silver >= b
```

를 만족할 수 있다.

하지만 실제 운반 가능량은 100뿐이라

```
70 + 70 = 140
```

을 동시에 옮길 수 없다.

따라서

```java
total >= (long) a + b
```

조건도 함께 확인해야 한다.

---

## 6. 최종 판별

특정 시간 `T`에 대해

```java
gold >= a &&
silver >= b &&
total >= (long) a + b
```

를 모두 만족하면 해당 시간 안에 금과 은을 운반할 수 있는 것이다.

---

## 7. 전체 알고리즘

1. 이분 탐색으로 시간을 결정한다.
2. 중간 시간 `mid`를 선택한다.
3. `can(mid)`를 통해 해당 시간 안에 운반 가능한지 확인한다.
4. 가능하면 더 작은 시간을 탐색한다.
5. 불가능하면 더 큰 시간을 탐색한다.
6. 최종적으로 가장 작은 가능 시간을 반환한다.

---.
# 시간 복잡도

- `can()` : O(N)
- 이분 탐색 : O(log(10^15))

따라서

```
O(N × log(10^15))
```

---

# 공간 복잡도

```
O(1)
```

# 배운점 

## Parametric Search

정답 자체를 찾는 것이 아니라

```
이 시간이 가능할까?
```

를 판별하는 함수를 만든 뒤,

```
불가능 → 가능
```

의 경계값을 찾는 방식이다.

최소 시간, 최소 비용, 최대 길이 등을 구하는 문제에서 자주 사용된다.
