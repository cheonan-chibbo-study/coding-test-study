원형수열을 어떻게 필지,탐색할지를 떠올리지 못했다.


# 접근방법
1. 원형의 수열을 1자로 피기위해서 배열을 2배로 만들고 숫자를 넣는다
2. 이중 포문을 이용해 시작점 부터 길이 len 를 늘려가면서 수를 더한다
3. 수를 더한후 중복 방지를 위한 set에 넣는다
4. set의 사이즈를 반환한다
# 배운점 
## 원형을 피는법
1. 배열을 2배로 붙이기

제일 많이 씀.  
원래가

[1, 2, 3, 4]

원형이면
4 다음에 다시 1로 이어짐

[1, 2, 3, 4, 1, 2, 3, 4]

이렇게 뒤에 한 번 더 붙인다.

그러면 원형에서 이어지는 구간

3, 4, 1
4, 1, 2

이런 것도 직선 배열의 연속 구간처럼 볼 수 있디.
```java
코드
int n = elements.length;
int[] arr = new int[n * 2];

for (int i = 0; i < n * 2; i++) {
arr[i] = elements[i % n];
}

또는

for (int i = 0; i < n; i++) {
arr[i] = elements[i];
arr[i + n] = elements[i];
}
```

언제 쓰는가    
- 원형 연속 부분수열
- 원형 구간합
- 슬라이딩 윈도우
- 누적합

2. % 연산으로 다음 칸 연결하기

배열을 실제로 늘리지 않고,
인덱스만 원형처럼 돌리는 방법.

예를 들어 현재 위치가 i라면
다음 위치는

(i + 1) % n


```java
예시
for (int len = 0; len < n; len++) {
sum += elements[(start + len) % n];
}

```
이렇게 할시 start + len이 n을 넘어가도
자동으로 다시 앞쪽 인덱스로 돌아온다.

언제 쓰는가
- 배열 복사 없이 원형 처리하고 싶을 때
- 회전 시뮬레이션
- 요세푸스 같은 문제
3. 앞부분과 뒷부분으로 나눠 생각하기

이건 “원형이 꺾이는 지점”을 기준으로 나눠서 생각하는 방법.

예를 들어 원형 구간이

4, 1, 2

이렇게 끊겨 있으면

뒤쪽 부분: 4
앞쪽 부분: 1, 2

로 나눠서 생각할 수 있음.

즉 원형 구간은 사실

배열의 뒤쪽 일부 + 배열의 앞쪽 일부

형태.

이걸 코드로 쓰면
```java
if (start + len <= n) {
// 안 끊기고 한 번에 감
} else {
// 뒤쪽 + 앞쪽으로 나뉨
}

```

근데 코테에서는 이 방식보다
보통 2배 배열이나 % 연산이 더 깔끔하다.

4. 첫 원소와 마지막 원소가 붙어 있다는 점만 따로 처리하기

이건 원형 전체를 펼친다기보다는
“양 끝이 이어져 있다”는 제약만 처리하는 방식.

예를 들어 원형 집 털기 같은 문제는
핵심이 원형 구간합이 아니라
첫 번째와 마지막이 동시에 선택되면 안 된다는 점.

그래서

첫 번째 포함, 마지막 제외
첫 번째 제외, 마지막 포함 가능

이렇게 두 경우로 나눠서 선형 문제 2번 푸는 식으로 원형을 푼다.

즉, 이건 원형을 펼친다기보다
원형 제약을 쪼개는 방법.
