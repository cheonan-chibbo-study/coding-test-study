# 30분내 어디까지 풀었는가
풀지못함
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.
완전탐색방식으로 모두다 시뮬레이션방식으로 하면 시간초과가 날수있다고 생각함    
그래서 최대공약수나,최소공배수 중 하나를 사용해서 주기 문제를 풀어야곘다고 생각했지만 구현방법이 떠오르지 않았다.


# 접근방법
1. 각 신호등의 `초록, 노랑, 빨강` 시간을 보고 전체 주기를 구한다.
    - `주기 = 초록 + 노랑 + 빨강`

2. 시간을 그대로 쓰지 않고 `x = t - 1` 로 바꿔 생각한다.
    - 이렇게 하면 각 신호등이 몇 번째 초에 어떤 상태인지 나머지 연산으로 표현하기 편해진다.

3. 각 신호등이 노란불이 되는 나머지 조건을 구한다.
    - 예를 들어 `G, Y, R` 이라면
      `x % (G + Y + R)` 값이 `G ~ G + Y - 1` 범위에 있으면 노란불이다.
    - 즉, 신호등마다
      “이 주기로 나눴을 때 나머지가 이 값들 중 하나여야 한다”
      라는 조건으로 바꿀 수 있다.

4. 모든 신호등을 동시에 만족시키려면
   각 신호등의 노란불 나머지 후보를 하나씩 골라서
   공통으로 만족하는 시간이 있는지 확인해야 한다.
    - 예를 들어 어떤 신호등은
      `x % 5 = 2`
    - 다른 신호등은
      `x % 7 = 5`
    - 이런 식의 조건으로 바뀐다.

5. 이렇게 만들어진 여러 나머지 조건을 하나씩 합쳐간다.
    - 첫 번째 신호등 조건을 기준으로 잡고
    - 두 번째 신호등 조건과 합칠 수 있는지 확인하고
    - 가능하면 둘을 만족하는 더 큰 주기로 묶는다.
    - 그 다음 세 번째, 네 번째 신호등 조건도 같은 방식으로 합친다.

6. 조건을 합치는 과정에서
   서로 동시에 만족할 수 없는 경우는 버린다.
    - 즉, 어떤 나머지 조합은 공통 시간이 아예 없으므로 탐색하지 않는다.

7. 끝까지 모든 신호등 조건을 합친 경우,
   그때 나온 시간이 모든 신호등이 동시에 노란불이 되는 후보 시간이 된다.
   여러 후보 중 가장 작은 시간을 답으로 선택한다.

8. 마지막으로 처음에 `x = t - 1` 로 두었으므로
   실제 정답 시간은 `x + 1` 로 바꿔 반환한다.
