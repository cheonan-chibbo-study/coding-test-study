# 30분내 어디까지 풀었는가
30분내 풀지못함 인접행렬 방식으로 풀려다가 잘못풀어서 시간초과
# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.


# 접근방법
1. 1~n 까지 전선을 끓고 인접리스트 방식으로 그래프를 만든다
2. 전선이 끓긴 그래프 를 만들고 dfs 를 통해 노드의 갯수를 탐색한다
3. dfs 의 경우 부모 노드에서 자식노드의 수를 누적으로 더하는 방식을 사용해 갯수를 구한다
4. 끓긴 노드수를 구하고 총노드수를 빼 다른 노드수를 구한다
5. 두개의 노드수를 뺸후 절대값으로  바꾼다
6. 절대값이 가장 작은값을 반환한다
