하루별 공부 방식

각 문제마다 이렇게 하면 좋아.

1. 완전탐색으로 하면 왜 안 되는지 먼저 생각
2. 정렬이 필요한지 확인
3. left/right 또는 stack이 필요한지 판단
4. 직접 예제 1개를 손으로 시뮬레이션
5. 코드 작성
6. 틀리면 반례부터 찾기

특히 이번 6일치는 목표를 이렇게 잡으면 돼.

그리디:
- “지금 선택이 나중에도 손해가 아닌 이유”를 설명할 수 있어야 함

투 포인터:
- left가 언제 움직이는지
- right가 언제 움직이는지
- sum을 언제 더하고 빼는지
  를 말로 설명할 수 있어야 함
