# 왜 못풀었는가 - 
### 풀이가 안떠올랐는지 / 어떻게 풀지는 알겠는데 구현을 못하겠다.
bfs 방식으로 풀었지만 word 를 끝까지 못찾을시 visited 의 상태를 되돌려야하는데 bfs 방식으로는 이게 힘들기때문에  
dfs 방식으로 풀어야했던 문제였다

# 접근방법
1. 처음 생각한것은 완전 탐색해서 문자를 찾아야겠다였다
2. 그리고 그중 bfs, dfs 중 고민하였는데  m x n 의 보드이므로 bfs 를 사용해서 탐색해야겠다고 생각했다
3. 큐에 현재 row , column, 인덱스 를 넣었고 다음 보드가 범위를 초과하지않고 방문하지 않았으면서 찾는 다음 단어라면 그 보드판을 탐색하도록 짰다
4. 그러나 이렇게 짜게될시 시작 보드판에서 결국 단어를 찾지 못할시 visited 를 돌릴 방법이 없으니 다음 단어 탐색을 하지 못하게되는 문제가 발생한다
5. 그렇기때문에 dfs 방식인 재귀 방식을사용해 bfs 와 유사하게 풀되 단어를 끝까지 찾지 못할시 방문했던 판을 초기화하는 코드를 추가한다.


# 시간/공간 복잡도
## 시간 복잡도:
O(M × N × 4^L)  
M×N : 시작점  
L : 단어 길이  
각 칸마다 최대 4방향 탐색
## 공간 복잡도:
visited 배열  
O(M × N)  
재귀 호출 스택  

최대 단어 길이만큼 들어감.   

O(L)  
L = word.length()  
최종  
O(M × N + L)  

보통은:

O(M × N)

으로 표현함.
