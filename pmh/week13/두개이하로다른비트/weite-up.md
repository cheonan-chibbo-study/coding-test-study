# 접근방법
### 핵심 규칙
x 가 짝수면 마지막 비트는 0이다  
예)
- 2 = 10
- 3 = 11  
그래서 맨 끝 0 을 1로만 밖면 x+1 이 되고 비트도 1개뿐이라 가장작다  

x 가 홀수면 마지막 비트틑 1이다  
예)
- 7 = 111 
- 11 = 1011 
- 13 = 1101  
그래서 홀수는 단순히 +1 하면 비트수가 많아 질수있디  
오른쪽에서 처음 나오는 0을 1로바꾸고 , 그바로 오른쪽 1을 0 으로 바꾸면 비트 2개만 바꾸고 가장 작은 더 큰수를 만들수있다.
예:
- 7 = 0111 
- 오른쪽에서 처음 0은 앞의 자리
- 0111 -> 1011 = 11  
이걸 식으로 바꿀시  
홀수에서 뒤에 연속된 1의개 개수를 생각하면  
예) 
- 7 -> 0111 뒤에 1이 3개 k=3
- 가장 오른쪽 0을 1로 바꿀려면 2^k,  2^3 을해서 더한다 -> 7 + 8 = 15
- 15 -> 1111 , 이걸 1이된 바로 오른쪽의 비트으로 0으로 바꾸면 -2^(k-1), -2^(2) -> 15 - 4 = 11
- 11 -> 1011
- 결과적으로 식이 7 + 2^k - 2^(k-1) 이 되므로 
- 2^k - 2^(k-1)  
  = 2 × 2^(k-1) - 1 × 2^(k-1)  
  = (2 - 1) × 2^(k-1)    
  = 2^(k-1)  
- 최족식이 x + 2^(k-1) 가 된다
- 이걸 좀더 쉽게 쓰면 -> x + 1 + ((x XOR (x + 1)) >> 2) 가된다
- ```java
    x + 1 + ((x XOR (x + 1)) >> 2)
  ```
- 위의 식이 x + 2^(k-1) 가되는 이유는
- 예) 7

- \>>2 같은경우는  
비트를 오른쪽 2칸 으로 미는것인데 1111 을 오른쪽 두칸으로 밀면

- 최종적으로 x + 1 + (2^(k-1) - 1) 이되고 
- 정리시 x + 2^(k-1) 이렇게된다
  
# 배운점 
1 + ((x ^ (x + 1)) >> 2) => 2^(k-1) 기억하기

# x + 2^(k-1) 으로 푼 코드
```java
class Solution {
    public long[] solution(long[] numbers) {
        long[] answer = new long[numbers.length];

        for (int i = 0; i < numbers.length; i++) {
            long x = numbers[i];

            // 짝수면 마지막 0만 1로 바꾸면 되므로 x + 1
            if ((x & 1L) == 0) {
                answer[i] = x + 1;
            } else {
                int k = countTrailingOnes(x); // 뒤에서부터 연속된 1의 개수
                answer[i] = x + (1L << (k - 1));
            }
        }

        return answer;
    }

    private int countTrailingOnes(long x) {
        int count = 0;

        while ((x & 1L) == 1L) {
            count++;
            x >>= 1;
        }

        return count;
    }
}
